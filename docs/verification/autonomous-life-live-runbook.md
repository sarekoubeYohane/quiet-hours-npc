# 自主生活循環有限正式驗收交接（#181）

此流程尚未執行。需要使用者另行授權部署及有限付費模型觀察；本輪不部署、不呼叫付費模型、不重置或推進正式世界。本地 fixture 不能替代這份驗收。

## 開始前

1. 記錄 PR／部署 SHA、`/api/environment`、UI 版本、台北時間及操作者。確認必要 migrations 與現行回合政策一致；不為此改 timeout、固定租約或預算。
2. 確認自動運行已暫停、沒有其他分頁操作；GET 目前世界與原操作。pending／uncertain 先依原 ID 查詢恢復，不開新 ID 重做，也不讀憑證本文。
3. 取得隔離世界授權並保存原世界證據；如目前不是可安全使用的隔離場景，先停止。重建、切換或重置另行取得授權，不以測試理由改寫既有故事。
4. 核對 NPC 模型、裁定模型、Key configured／到期狀態、回想啟用狀態與玩家／站主預算。記錄四項需求的啟用時間、活動、物件、喜好及習慣起點，不預先灌入模型評價或虛構跨日歷史。
5. 授權必須明列整批回合／calls／tokens／實際時間硬停止上限，及下一輪開輪餘量；缺任一項即不開始付費。不要把歷史 #171 的上限自動當成本輪已獲授權。跨日所需回合可能超出一次授權，屆時停止並分批接續原隔離故事。

## 待授權的工程建議上限

以下僅為後續授權範本，**本輪沒有啟用**：每批最多4次advance、32次實際聊天派送、500,000已知tokens及首個付費呼叫起30分鐘，任一先到即停。最多四角色且回想關閉時，下一完整輪保留8次聊天餘量；回想啟用時保留12次聊天及4次回想服務餘量。tokens另保留250,000作下一輪保守開輪餘量；它不是provider硬上限或精確費用預約，實際授權可選更小上限。

下一輪開始前，剩餘calls必須容納完整合法鏈，且tokens／實際時間餘量足夠；不在中途為湊案例提高限制。世界時間每次可選原介面15／30分鐘，數小時睡眠及跨日習慣可能需要多批。前批未到達就記未到達，保存原隔離故事，取得後續明確授權再接續；不能把本地快進或重建三日證據當正式觀察。

## 有限觀察

- 每次只提交一個 advance，保存 operationId、世界日／時間、version、預期可觸及情境。等待原操作完成後才開下一輪；按既有 world API 粒度推進，不使用測試專用控制或背景連跑。
- 對照本輪實際 NPC request 中的本人感受、自己喜好、相關習慣與可見經歷。觀察者權威數值、隱藏工具去向、他人私有經歷、裁定理由及 trace 不能注入 NPC。
- 追蹤「需求增加 → 主動處理或延後 → 真實物件消耗／已發生時間恢復 → 下一次主觀評價 → 後續選擇」。保留同物件身份、剩餘量、容器及活動 cursor，不以 accepted 或成功文字當完成證據。
- 覆蓋長工作自主暫停、插入飲食／休息、自主復工；若 NPC 沒有選擇此路徑，記未到達，不用直接控制或提醒逼出自主證據。可另列直接控制的機械對照，但不能混算自主習慣。
- 睡眠須確認真正開始，至少跨原 90 分鐘界線，記錄逐段恢復、自然醒／足夠可知刺激及醒後選擇。普通飢渴不應反覆叫醒。未選睡眠或未到自然醒分開標示。
- 喜好須由當次正常決策明示維護且引用本人合法可知經歷；成功、失敗、骰級與需求降低不直接證明喜好。保留形成、維持、修正或放下的原回覆與持久化差異。
- 習慣須有真正開始且已提交的自主活動與跨多個世界日證據。事件型來源須在當次可見引用、時序合法；同日多輪、純續做、復工、否決、直接控制及重送不得刷強度。
- 每輪記錄 NPC／裁定／回想 calls、已知 input/output tokens、未知用量與規則重用；純時間及階段推進不得額外裁定。下輪開輪餘量不足時即停止，不因未到場景而提高上限。

## 停止與恢復

任一授權上限、錯誤、狀態不一致、超出隔離範圍或 pending／uncertain 即停止自動與新操作。只讀原 ID 及已提交世界，保存原始錯誤、已知用量、版本與時間；不要換 ID 重抽、不提高限制、不清除 journal、不重置。確定 rolled-back 時核對故事共同回復及早先已提交成果；結果不明時沿現有 UI 原操作恢復，不手動套用候選。

## 報告格式

每項結果標為 **已觀察到／未到達／技術中斷無法判定**，並連到去識別化的 operation／版本／世界時間與證據。列明部署、模型、授權及實際回合／派送／用量差額、停止原因、初始化與資料缺口。完整私人 transcript、記憶正文、憑證及世界備份不納入公開 repository。

機械 fixture 與真實模型行為分欄；不要求每個 NPC 在固定輪數內吃喝、睡眠或喜歡某事，不以短時間無循環證明不存在。不因此關閉 #85／#104／#106，不宣稱泡茶 loop 全部修復。
