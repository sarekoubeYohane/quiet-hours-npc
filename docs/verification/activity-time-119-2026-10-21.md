## API 覆蓋

新增7項API測試：

1. 介入後自主換事，保留已提交水與物件，取消未來飲品；重載、重送及後續到期無新增成果或派送。
2. 自由首次確認30分鐘茶→完成→接管／直接指定重用→完成→交還→規則模式重用。整條只有首次1次NPC及1次裁定；兩個後續活動均不派送模型。
3. 60與90分鐘完成目標遇介入時續做，保留原起點／到期／時間語意／cursor；45分鐘開放式活動同樣不重設計時，到期續做不延長。
4. 另一NPC透過真實世界API取得中間杯子並攜往其他場所；90分鐘舊階段失效，不復原物件或另造茶。原角色下一次輸入沒有物件或隱藏去向／移動者的診斷洩漏。
5. 後一回合中斷提交衝突，保留前一回合水、原60分鐘計畫與候選；同操作重送不再付費，之後自主續做仍可完成同一杯茶。
6. 接管／交還均取消未完成飲品候選而保留實際物件；沒有已確認規則的直接茶入口仍正常拒絕且無模型呼叫。
7. 直接整理依既有程式15分鐘結果完成，沒有另一個固定60分鐘完成門檻；直接休息沿既有60分鐘時段到期，保留接管模式，無模型派送。

既有控制及主動感知測試中的「持續60分鐘」fixture改用休息，因整理／觀察的完成目標已在 #118 接為單次15分鐘操作；仍驗證控制權、知情、觀察與原意圖，而非保留舊不一致計時。
