# #240 人物範本驗證

登入後從觀察室開啟「人物範本」。可從空白建立人物，也可按預設人物名稱建立私有副本。保存後可從「我的人物」重開。人物範本獨立於場景與世界保存，起始位置先保留描述。姓名必填，其他欄位保留輸入的空白和原文。

## 驗證

執行 `node --test tests/character-templates.test.mjs`。

- API 測試直接呼叫應用 route，使用實際 migration、SQLite 與正式查詢。建立兩位新角色、重讀十項欄位、保留「安靜」和有前後空格的內容。預設可讀但不能直接寫入，私人副本和其他帳號隔離。
- 另覆蓋同源寫入、過期版本、保存前及保存後的儲存故障，以及使用相同識別碼、版本與內容重送。保存前故障保留舊版，保存後重送不增加版本或建立副本。
- UI 測試在 Happy DOM 掛載實際人物編輯器，操作新建、輸入、保存、重新掛載後開啟、更新與預設副本。UI 請求交給同一個 route 和 SQLite。環境綁定與登入身分由 fixture 提供。

## 相容性

新增的 SQLite 表只保存人物範本，帳號識別由既有登入服務提供。儲存以範本版本防止過期寫入。僅最新一次相同版本與內容的保存可重放，更舊的請求會回報衝突。舊執行器可繼續讀取原世界，但沒有新人物範本入口，回退時保留這張表即可。後續城市組合由 #242 接續，人物自然語言與留白生成由 #243 接續。
