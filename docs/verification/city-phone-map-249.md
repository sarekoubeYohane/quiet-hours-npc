# #249 手機地圖驗證

城市手機可用既有 `phone` 行動，以 `{"collection":"map","operation":"read","offset":0}` 讀取一頁公開地圖。以已公開建築的名稱與場所身分標示位置，附上通往其他公開建築的直接道路和已保存步行時間。每頁最多一處建築及其公開道路。建築權限非公開時不列入。未通行的連接、私人室內、物件、私人手機內容及個別權限均未加入頁面。

只有實際操作有效裝置才把讀到的頁面寫入角色的普通短期經歷。裝置保存同一讀者、同一頁最新一次讀取供觀察，沒有資料庫遷移。閱讀紀錄不回灌角色。角色按既有記憶規則保留、忘記或再次查閱。觀察者從人物檔案開啟紀錄，不推進世界時間、不建立角色知情。裝置損壞、缺席或不可操作時，不能用舊裝置身分讀圖。

執行 `node tests/run-activities.mjs tests/city-phone-map-api.test.cjs`。先重現模型讀圖候選被拒絕、人物檔案缺少紀錄的紅燈。通過時，正式世界 API 建立城市，模型讀取前及未讀者沒有陌生目的地。一次真正讀取保存公開道路後，下一個決策收到該資訊，並依讀到的場所身分抵達書店。測試檢查 SQLite 重讀、同操作重送、實際人物檔案操作、未讀頁、私人資料與損壞後同一裝置的證據。模型回覆由受控 transport 提供。
