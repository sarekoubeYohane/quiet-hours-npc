## 授權、備份與場景差異

本次授權最多 6 次 advance、48 次實際派送、已知 input＋output 500,000 tokens，並遵守更低帳戶限制；手動逐回合、技術故障即停。接受保守 token 估算和最後已開始回合可能超過門檻，沒有要求不存在的精確預約能力。**本輪停止是版本不符，不是 token 上界或預算阻擋。**

保留原隔離故事，沒有重建、清空記憶、返回日常世界、改 DB 或改變觀察條件。未改 Playbook、泡茶政策、提示、模型、日常規則或物件，也沒有加「不要重複」提醒。版本變化以外沒有本輪主動安排的新舊場景差異。

本輪另私有保存可重讀 JSON 取證紀錄，包含部署 API 原值、UI 狀態、預算及原操作機械關聯；已 JSON 解析與 SHA-256 重讀校驗。它**只是本輪唯讀預檢紀錄，並非完整世界／私有實錄備份**。因版本門檻先停止，未進入推進前的完整備份階段，未重新匯出／重讀全部世界及舊 transcript，也未獨立驗證原日常世界暫存快照或還原。前次完整私有包的保存聲明仍只依前次報告，不能冒稱本輪重新驗證。

公開內容只有去識別化的部署／操作／用量／物件必要摘要；沒有完整 transcript、記憶正文、operationScope、Cookie、Key 或認證 header。
