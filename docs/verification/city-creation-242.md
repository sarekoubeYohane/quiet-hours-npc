# #242 手動建立城市

在觀察室按「建立城市」，為場景範本選擇數量並命名各處，勾選人物範本後為每人指定起始場所及房間。住處可以另行選擇。同住者選取同一個場所即可共用一份房間及物件，選取第二處相同範本則得到自己的房間、門與物件。

預覽沿 `POST /api/world` 的 `preview-city` 操作，返回可讀配置與起點問題。編輯會使畫面先前的預覽失效。開始沿 `start-city`、原有世界 CAS 與操作收據提交，使用相同設定和明示的世界與範本版本。預覽沒有改動回合或版本。已開始的世界仍可使用原本的推進入口。

同一個 SQLite 語句成功提交新城市時，migration 0008 的觸發器保存當時的原世界資料與版本。備份在同帳號的 `world_before_city`，與觀察 API 及角色輸入分開。設定及已知用量帶入新的運行世界，舊世界原始資料也保存在備份。本切片限定一次城市切換，還原與管理備份介面屬於另外的產品決策。回退前須保留新世界和備份表，舊版的運行器缺少自訂配置的讀取能力。

- 正式範本保存與世界 API 測試先在 `preview-city` 遇到無效操作，實作後驗證缺起點、過期版本、兩位自訂角色、兩處同源住宅、開始的提交回應遺失與同操作重送、重讀、原世界備份、用量及跨帳號隔離。
- 同一測試使用受控模型及原本裁定流程，打開其中一盞台燈。保存後另一處台燈保持關閉，來源場景範本保持原值。實際角色輸入含自己的背景，缺少陌生場所、舊世界歷史及另一位人物的私有背景。
- UI 測試掛載正式應用並操作範本數量、場所名稱、角色及起點。修改後需再次預覽，按開始後場景以場所、房間與文字呈現保存狀態。
