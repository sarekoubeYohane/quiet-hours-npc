# #83 再運行一小時費用推估

## 範圍與採樣

實作：`components/forecast-panel.tsx`、`components/world-app.tsx`。世界 API 的 `costSummary` 與 `world.aiUsage.costs`（#82）是已發生費用依據，推估只讀取累計差額，不新增帳本或資料庫遷移。

採樣窗口為最近 10 分鐘的同一次前景自動運行；最低為 2 個完成回合及 30 秒。開始建立費用基準，完成世界推進讀回後建立下一點，費用差額除以兩點之間的實際時間，再乘 3,600 秒。正常間隔、活動動畫及模型處理時間都計入。手動推進沒有自動節奏，不累積推估樣本。相同世界時間重讀、操作結果重播及預算設定不增加點數；即使回合延續既有活動沒有模型呼叫，仍是真實完成回合，可記錄完整零差額。

暫停保留已採得的假設性推估、凍結時間並明示停止；恢復重新建立基準，長空檔不被算入。背景停止與錯誤沿用既有自動控制。供應商、模型、價格版本、間隔、世界時間步長或重新載入會重建元件，失去不適用樣本；世界時間倒退、時鐘倒退、累計計數倒退及不相容模型差額也使樣本重新開始。運行時每秒檢查證據時效，因此長時間未完成請求不能繼續展示超過 10 分鐘的有效樣本。

只對本次累計差額判定未知，舊未知帳不污染新的完整樣本。未知價格／用量只顯示部分已知小計或無法完整推估；明示零價且完整用量可推估 USD 0。結果取兩位有效數字。站主費用獨立標為未知；推估不是扣款、金額上限或保證一小時運行，也不變更用量或控制。
