# #243 自然語言人物草稿驗證

在觀察室設定天上意志的服務、模型與已保存的 API Key，然後到「人物範本」新建或開啟人物。輸入描述或先手填欄位，按「用 AI 生成空白欄位」。成功後檢查、修改，並用原本的保存按鈕保存。

空白指空字串。已填的短文字、明示「沒有」或空格都會原樣保留。人物描述只用於生成草稿，個別欄位保留哪些結果由使用者確認。系統會拒絕格式不符的候選，語意是否符合描述仍由使用者檢查。

## 測試

- `node tests/run-activities.mjs tests/character-generation-api.test.cjs` 先確認舊路徑回傳 400。實作後經正式世界 API、SQLite 與受控模型回覆驗證模型輸入、填入規則、計量、同 ID 重送、跨帳號隔離、預算達上限、保存前／後故障及世界時間與人物不變。
- `node --test tests/character-templates.test.mjs` 掛載原人物編輯器，經實際人物與世界 route 及 SQLite 操作描述、生成失敗、填入空白、修改、保存與重開。生成結果在保存前不會出現在範本清單。
- 使用真實模型 transport 契約及受控回覆。沒有量測付費模型產生內容的品質。

## 操作邊界

生成沿用世界操作租約、帳號範圍、玩家預算及用量收據。成功或失敗的模型嘗試皆保留可確認的用量。同一操作識別碼可重讀原收據，模型草稿不會加入現有角色、記憶或世界事件。編輯器若收到未確定結果，在本頁以相同內容再按生成時會沿用同一識別碼。切換人物或離開頁面後依原操作收據保留規則處理。
