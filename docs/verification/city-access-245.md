# #245 進出權限驗證

場景範本可設定建築預設規則，房間可沿用或另設規則。身分條件在每次城市預覽及開始時，依具體場所的住戶與員工重新對應。個別授權可指定建築或房間，不會修改住處、工作、門的狀態或來源範本。建築個別授權只傳給沿用建築規則的房間。

開始後，權威世界保存已對應的允許名單。直接移動由既有空間與門判斷物理可行性，移動事件另外記錄實際授權，僅在觀察者詳情顯示。天上意志裁定輸入只取得本次相關區域的授權判斷。NPC 決策照既有感知與記憶投影取得線索。沒有額外資料庫遷移。舊世界省略權限設定並保留原有行為。

- API 紅燈重現場景保存拒絕權限資料。兩項 UI 紅燈分別重現場景權限與個別授權控制不存在。
