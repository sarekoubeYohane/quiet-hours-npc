## Red → Green

每輪先新增一個世界 API 垂直切片，執行失敗後才增加對應程式。實際 log 保存為工作環境外部的 `evidence/53-01-red.log` 至 `53-15-red.log`，各自對應 `*-green.log`；下表記錄可重現的失敗內容，不把驗收清單當作已執行測試。

| 切片 | Red | Green |
| --- | --- | --- |
| 01 信念→意圖→合法行動 | API 502，預期 200 | 同次保存信念、意圖、移動、現在情緒，operationId 重放不多呼叫 |
| 02 改觀／堅持／撤回 | 第二次更新 API 502 | 相同 ID 版本更新、保留短理由、舊看法不進後續模型輸入 |
| 03 情境信任／舊關係撤回 | 標籤候選 API 502 | 同人物多話題、keep／withdraw，舊文字不恢復 |
| 04 誤信／未解矛盾 | 第二個相反信念 API 502 | 深信與存疑共存，不自動改觀或強制行動 |
| 05 有界相關標籤 | 未展示標籤被撤回，API 200 | 最多 8 個相關候選，未展示修改 API 502 並整回合回復 |
| 06 共同輸入預算 | 加入信念後模型輸入超過 88 KiB | 短期完整保留，省略長期／認知仍留在正式保存 |
| 07 共同操作上限 | 4 選留 + 1 認知仍 API 200 | 超限及越權／過期引用整回合回復，保留兩次已付用量，重放原失敗 |
| 08 歷史容量釋放 | 無歷史候選，API 502 | 明示遺忘中介資料，硬滿後仍能連續改觀，不復活舊全文 |
| 09 正式資料限制 | 重複信念身份 GET 200 | 重複身份、完整舊文、超長理由 GET 503，不讓無界歷史進模型 |
| 10 現行情緒／續做 | 延續仍保留「難過」，預期新情緒 | 重新理解後選 continue 可更新情緒，原計畫及完成時間保留，沒有專用呼叫 |

| 12 硬滿時整份候選取捨 | 全部 24 筆真實 changed anchor 被引用，合法移除最後引用者並釋放舊鏈仍 API 502 | 同份候選明示改變引用後可釋放 metadata，兩種操作順序都成功；仍被引用的 anchor 候選被拒 |
| 13 已知消息來源 | 已收到 observer 消息，新增其關係標籤仍 API 502 | actual visible sender 納入已知人物；匿名未知／world／system 仍不能建標籤 |

| 15 共同整理候選上限 | 同時有現行／歷史容量壓力，提供 8+8 個整理 handles | 合計最多 8 個；同時壓力各分最多 4 個，只有一種壓力仍最多 8 個，不刪保存內容 |

其中共同操作上限的 fixture 先修正為每個 NPC 確實有四筆可見短期，再取得有效 Red；未把不足四筆的錯誤 fixture 當作功能缺陷。測試斷言狀態、權限、用量與保存，沒有鎖定真實模型必須產生的台詞。

## 審查與尚待驗收

兩軸 code-review（Standards／Spec）由整體 implement-spec 協調者執行。Standards 發現 1 項 P3 Data Clumps，已在審查階段以 `CognitiveDecisionContext` 收攏實際可見資料與權限邊界，複審剩餘 0。Spec 發現容量死結及其硬滿全 anchor 邊界、已知消息來源無法建立標籤，以及整理候選未跟隨輸入預算裁剪；第 11–14 切片各以 Red → Green 修復，真正仍被引用的 changed／withdrawn 版本來源保持受保護，複審剩餘 0。Spec 四項實際問題全部修復，另自行補第 15 切片的共同整理候選上限。最終審查基準為 `8eb048ed579dafb4cf23a85813b9aee105eaba60`，Standards 與 Spec 各剩餘 0 findings。自然語言「相近」更新由模型判斷，程式只強制相同主題／身份與引用、版本、格式／容量，無法證明每句信念忠實。實際模型可選擇不形成信念或不改觀；測試替身通過不代表真人模型品質已驗收。

沒有正式 migration、重置世界、付費 smoke test、服務啟用或正式站驗收。新資料仍在世界 JSON 中，但同人物多標籤的兼容 `relationships` 文字可超過 256 bytes；若日後回退至 #52 舊 validator，合法新存檔可能被拒絕，因此須先備份並準備相容讀取／轉換，不能把直接 revert 程式當作已驗證的資料回退方案。`Character.cognition.trace` 可辨有限狀態，但不保存所有舊全文；模型明示釋放後也不宣稱全部歷史仍可查。未增加唯讀 UI。

## 操作與可觀察證據

下列正式站操作須等 PR 由使用者合併並部署後才適用；本輪沒有執行線上操作或付費聊天。

| 操作 | 預期與證據 |
| --- | --- |
| 對 Cass 提供新的相處經歷，再正常推進 | 角色可以接受、懷疑或不形成信念；用開發者工具 `fetch('/api/world').then(r=>r.json())` 查看 `world.characters`，正式信念在 `cognition.beliefs`，不假裝舊面板已有信念 UI |
| 先提供支持、之後提供相反說法，再推進 | 若模型選擇改觀，同 ID version 增加、trace 記錄舊版本與短理由；選 keep 亦有理由；可形成明示 contradictions 而非必定理性修正 |
| 分別談同人物的不同話題 | `cognition.relationshipTags` 可包含同 person 的多項 topic，`relationships` 僅為兼容文字投影；這是主觀情境信任，沒有信任分數 UI |
| 接管店主並讓其他 NPC 延續原活動 | 店主 cognition 不因整理被喚醒；沒有新增記憶專用模型用量。交還後按正常決策時機重新評估 |
| 本機執行 `node tests/run-activities.mjs tests/cognition-api.test.cjs` | 15 個可控情境驗證讀回、誤信／矛盾、候選權限與容量、付費失敗重放，不需要正式 Key 或修改正式世界 |

真正判斷規則是否守住時以 API fixture 為準；真人台詞及自然語意是否合適另需有界人工檢視。
