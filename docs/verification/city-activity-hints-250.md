# #250 自訂城市的活動提示驗證

NPC 的正常決策可收到 `activityHints`。提示從本人目前可知的物件及眼前區域產生，最多包含六個物件及一個查看區域的提示。提示依既有模型輸入容量裁減，並保留原本的已知方法。物件名稱、狀態欄位及所在取自已完成的主觀投影，提示不查權威物件、進出許可或裁定可行性。

角色可採用提示、修改方法或提出提示外的行動。實際嘗試沿原本世界裁定、效果驗證及回合保存。提示本身不改變世界、權限或角色記憶。

## 驗證

執行 `node tests/run-activities.mjs tests/city-activity-hints-api.test.cjs`。

- 正式人物、場景及城市 API 建立兩位自訂人物和兩間工坊，使用 SQLite 重新讀取。
- 實際 NPC transport 中，兩人面對相同可見物件時取得相同提示。只有其中一處有隱藏安全卡榫，角色輸入未帶入該物件或權威判斷理由。受控裁定辨識實際條件後，一處成功保存物件新狀態，另一處保留原狀並記錄受阻。
- 下一回合以沒有出現在提示清單的托盤提出自由方法，正常裁定後保存新狀態。實際掛載的觀察畫面經正式 API 重新讀取，切換場所可見兩種結果。
- 模擬成功保存後失去回覆，以同一識別碼重送。結果與用量保持原樣，沒有再次派送模型。

驗收使用受控模型回覆。沒有測量付費模型選擇提示的品質。
