# #241 場景範本驗證

`/scene-templates` 提供資料編輯器及預設場景美術預覽。房間、連接及文字物件使用資料身分。物件可保存明示初始狀態，沿用世界的有界狀態契約。城市組合可從 `GET /api/scene-templates` 選用範本，並將範本內的房間、連接及物件身分映射到實際世界配置。

目前的邀請登入用於私人製作與保存。共用住宅由程式提供，製作者可從共用範本建立私有副本。SQLite migration `0007_scene_templates.sql` 新增獨立表，以帳號與範本 ID 隔離。修改使用版本條件單次提交。原版、其他帳號的內容及既有世界資料不受範本保存影響。

## 重現

執行 `node --test tests/scene-templates.test.mjs`。測試使用產品 route、原生 SQLite 與實際 React 編輯器。登入與 D1 接線由測試邊界提供。

- API 紅燈先重現缺少保存入口。綠燈建立兩房間、一連接、床、小桌與台燈，重讀確認全部資料與已明示狀態。
- UI 紅燈先重現缺少編輯器。綠燈操作新增、修改、保存與重讀，驗證兩間房、物件及狀態。
- 持久化反例驗證無效房間參照、跨來源、保存不可用、舊版本、跨帳號、未登入及共用原版覆寫。

手動操作可在登入後從「場景範本」開啟。新增範本後填寫場所、房間、連接及物件，保存，再重新讀取。預設美術沿用夜景素材。實際城市複製由 #242 接通。權限條件由 #245 擴充。
