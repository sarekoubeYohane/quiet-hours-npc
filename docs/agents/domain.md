# Domain Docs

本專案採 single-context。

## 開始工作前

讀取根目錄的 `GLOSSARY.md`，以及 `docs/adr/` 中與本次工作相關的決策。
文件不存在時直接繼續，不預先建立空白文件。
domain-modeling 在用語或決策確認後，才建立或更新對應文件。

## 用語與決策

Issue、規格、程式與測試使用詞彙表定義的用語。
新概念尚未定義時，先確認是必要的新概念，再由 domain-modeling 補充。
若方案與既有 ADR 衝突，明確指出衝突與重新討論的理由。

詞彙表記錄設計用語，不代表功能已完成；實作狀態以程式碼與驗證結果為準。
