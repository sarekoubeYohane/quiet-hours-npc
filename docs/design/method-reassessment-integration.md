# 方法重評估與可靠承接：整合契約（#186／#201）

角色依目的及本人資訊自行選方法；天上意志確認外在可行性及後果；活動／效果／唯一世界提交負責可靠承接。受阻不強制改動作、清意圖、安排吃喝或按次數處罰。

## 一條責任鏈

`本人仍保留的來源 → 最後已知索引 → 同次方法評估及 action → 已確認規則或原裁定 slot → 當前綁定／活動／真正效果 → 同輪保存 → 下一次實際輸入`。

- **可知狀態**：沿既有 short／long／觀察來源與時間；有界索引不從私有 trace、隱藏庫存或許可名單補事實。知道某個 supply 身份不表示知道現在有貨；過去攝取也不表示整間店沒有替代來源。來源遺忘後索引不得復活內容。見 [#194](../verification/last-known-state-194.md)。
- **同次評估**：`npc-decision.v2` 的巢狀 action 與 methodAssessment 在同一次正常決策提交；引用只限當次可見版本，selectedAction／intents 可機械對照。這是主觀自述，不是外在事實、永久方法記憶或行動命令。見[完整 #195 契約](method-assessment.md)。
- **來源及替代方法**：v3 來源主題、來源身份、當前可達及權利分開；指定舊餐點耗盡不封鎖另一來源。操作者背景確認入口與訪客使用具體合法來源／physical 後果分開，請求不代另一角色同意。#198 的代表路徑已存在，新增跨回合證據沒有任意放寬驗證器。
- **方法重用**：operation、場所／知情、角色與 guard 為邊界；明示核准的成對 aliases 可重用，不交叉組合配對、不用文字相似度猜未知語義。新對象每次重新綁定，舊 v1/v2 不因讀取補別名或身體後果；方法列表不是封閉選單。
- **免費受阻**：只承接已有可驗證前提、尚未開始的失敗；有界 server-only confirmedSources 保留已確認來源身份及必要事實。相同障礙重驗免費，真正新來源／scope 不因舊狹窄條件被封死。技術格式、關聯歧義、unsupported、逾時或預算故障不成永久世界禁令。
- **容器及份量**：linked 明示 to-role／from-role，舊缺方向仍原義；多解不能任選。1 item 可在一次正常裁定確認同源 partition 粒度，再 separate→ingest，餘量及原杯關聯保留；不讀取時推定毫升。普通 consume 不自動變成需求恢復，accepted／綁定／階段／實際提交分開。

別名、關聯、同源粒度與來源錨點的資料上限及精確相容策略集中於[通用世界變更契約](world-changes-framework.md)。代表跨回合驗證及全部驗收映射見[#201 報告](../verification/method-reassessment-201-2026-10-27.md)。

## 保存、容量及相容

沒有新增資料庫 migration。新增 v3 別名、linked 方向、已確認來源 guard 等欄位寫入後，舊 binary 不一定理解完整方法／綁定／資訊語義；**資料語義回退為單向門**，回退需保留可理解新資料的讀取及執行能力，不可刪欄位、丟來源、重置或把新 guard 忽略成已合法。

lastKnownState 至多8筆／8KiB並受既有記憶輸入預算整理；methodAssessment 至多2KiB、納入同次心理工作量；knownMethods 至多16筆。這些不是宣稱整份 request/schema 也受88KiB硬上限。規則、來源錨點、操作證據與私有 trace 保持各自上限及缺口；讀取、重送、純階段推進與免費匹配不新增模型。已知用量、保存衝突、期限／租約、較後角色錯誤沿既有整輪候選及回復，未提交認知或世界成果不得留下半套。

本輪組合測試以受控 wall clock 每次操作間隔15分鐘；每次仍只推進15世界分鐘，不修改任何 hourly budget、派送上限、模型輸出、HTTP期限或租約。這是讓長故事跨正常小時視窗執行的人工時間，不代表短時間內可超過現有額度。

## 與手機工作的接點

#185／#187–#193、PR #202 是獨立進行中的工作，不是本輪前置，未把其未合併行為算成本輪已測。保護其分支／worktree。之後整合須沿共同 Action／allowedTypes 與巢狀決策 schema，手機／前瞻記憶若提供來源須遵守當次知情與短長期版本，附帶操作及活動仍共用唯一時間／效果／原子保存；不能另建第二個決策、記憶或提交引擎。新來源與方法提示仍須有界，不能把私人訊息、未讀預覽或提醒當成既已讀取的知識。


### PR #203 衝突整合（2026-10-27）

PR #202 已合併至 main；本次將其手機／柔性安排與 #203 方法重評估接回同一決策流程。`normalDecisionInput` 統一提供 `npc-decision.v2`，保留手機知情引用、通知／安排線索及有來源的最後已知索引；回想後仍重新依可見記憶整理。手機 action 沿 v2 巢狀 schema 與方法評估對照，手機引用驗證、安排更新及知情回執保留。六類心理更新共同最多4項，連同 interpretation／methodAssessment 共用8KiB，而方法評估本身仍最多2KiB。

新增公開 API 回歸案例：同次 v2 決策保存手機備忘錄與有來源的稍後安排，保留方法評估追溯，只推進15世界分鐘；原 operationId 重送不新增派送或重複寫入。這是本地 transport fixture 證據，不代表正式站或真實模型行為驗收。
