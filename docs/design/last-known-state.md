# 方法相關的最後已知狀態（#194）

`self.lastKnownState` 是同次正常決策已可見記憶的有界索引；沒有新增持久知識表、摘要模型或從私有實錄恢復資料。每項保存 `reference.kind/id/version`、原始主觀文字、來源及世界分鐘。同輪主動回想的完整文字只放一次於`self.longTerm`，集中項使用`textLocation: self.longTerm`與原版本引用定位，避免重複回想本文。聽聞、推測、錯誤感知及彼此矛盾的帳述不會被合成權威真相。

先完成既有記憶輸入預算，再從真正會送出的短期與長期來源整理；最多8項、8 KiB UTF-8，並包含在原88 KiB記憶輸入預算內。同輪主動回想來源優先，其次按目前活動目標、意圖／背景或本人帳述內明示`[id]`與最新帳述的精確文字關聯，再按來源時間選擇；這只是有界檢索提示，不是語義匹配或世界驗證。`omitted` 明示其餘可見來源未集中列出的數目。餘量不足512 bytes時整份重複索引省略，保留原始記憶。

`gap` 明示未列出、已忘及未得知後續改變仍未知。短期淘汰、長期遺忘／濃縮、版本變更及輸入預算淘汰都沿原生命週期；讀舊世界不補歷史。consumed物件不重新進入active操作清單，原經歷內的指定物件身份仍可被引用。索引只保存來源原話，因此不從已消耗世界物件倒推出本人一定知道它耗盡，也不以最新隱藏真值校正錯誤印象。

供應投影的 `availability: unknown` 是所有已知供應一律相同的語義標記；身份存在不證明庫存、私人使用許可或補貨。指定那份用完只關聯該份；其他來源及未知補充不由程式宣告缺貨。一般否決不再預設許可不足，仍沿既有本人回饋保存原提案、對象、時間與尚未執行的結果。已開始、進展及完成沿既有活動回饋表述。

觀察者使用原決策實錄的實際request/messages與記憶來源對照；不新增分析頁的私人欄位傳入NPC。一般與免費日常路徑均經既有`recordActionResult`，原子世界提交、重送及已知用量不變。只有本地機械證據，不能據此宣稱真實NPC已採納或loop消失。
