# 自主生活長活動工程基線（#175、#176）

以下是工程選定的可調基線，並非使用者已確認的精確參數。

- 共同世界活動上界 1,440 分鐘（24 小時），以 15 分鐘為粒度；一般估時、完成時間與開放式時段共用驗證。涵蓋整夜睡眠與數小時工作，仍拒絕無界安排。每次 API 推進沿既有 15/30/60 分鐘入口與整輪提交，不改伺服器、模型、租約或預算期限。
- 保留最多四個有意義階段，不為每 15 分鐘建階段；原時長存檔維持原義，不由讀取延長。
- 每角色最多一個暫停活動；只有世界裁定明示 `resumable: true` 的活動可以暫停。舊候選／規則缺欄位視為未確認，不回填。
- 暫停保留原計畫、已執行階段游標、已投入分鐘、剩餘工時與當時參照的物件／供應條件。復工由正常決策選擇，原判定及階段效果不重放；外在自然變化持續。
- 復工採保守的原條件重驗：角色回原活動區域、被參照現存物件版本／狀態／位置／持有／許可與供應狀態皆須一致。改變後不以過期候選產生成果，可放棄後提出新方法。原因只給一般可知失效回饋，不揭露未知去向。
- 暫停槽滿不淘汰舊進度；明示放棄才清理未來候選。保存都沿原世界 JSON／SQLite 與操作日誌，不新增獨立提交。

測試介面沿 #172 已確認的世界 API、實際序列化／SQLite 保存重讀及既有畫面；模型 transport 與骰子可替身，活動／效果不替身。
