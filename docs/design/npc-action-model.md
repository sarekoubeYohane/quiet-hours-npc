# NPC 行動模式

狀態：grill-with-docs 訪談進行中。以下區分已確認設計與目前實作。

## 已確認設計

### 意圖與行動分成兩層

先有模糊的意圖，再依當下情境選擇具體行動。後續行動可隨現場情況調整，不要求一次排定完整步驟。

例如 Vera 的意圖是「想換個環境，做點自己的事」，可以先前往咖啡館，再依現場情況選擇畫髮飾或和人聊聊。

生活習慣是可改變的傾向，與意圖、行動的關係仍待釐清。

### 意圖強度影響時間

使用者已確認：隨意圖的強度來決定時間。

意圖維持時間與意圖強度相關；具體對應、重新考慮的條件，以及是否同時影響開始行動的時間與單次活動持續時間，仍待釐清。尚未確認任何數值或固定期限。

### 輕重緩急與性格

使用者已確認：先考慮事情的輕重緩急，再讓 NPC 按自己的性格處理。

事情的排序與具體處理需考慮輕重緩急及角色性格。排序是統一標準還是角色自身的判斷、性格是否同時影響排序與處理方式、如何處理互相競爭的意圖，仍待釐清。

## 目前實作

AI 每次回傳單一行動與持續時間。休息、工作、思考與觀察可延續多個回合；已有自主行動的習慣統計。尚未實作獨立的意圖層、意圖強度計時或明確的輕重緩急排序。

## 待釐清

- 意圖強度如何影響維持時間、開始時機與活動持續時間；何時重新考慮。
- 輕重緩急由誰判斷；性格影響事情排序、處理方式，或兩者。
- 多個意圖互相競爭時，如何切換、暫緩及恢復。
- 意圖如何形成，以及生活需求、目標、習慣的作用。
- 行動完成、失敗及事件打斷時如何處理。
- 半控制 NPC 的單次指定與暫時接管，如何影響意圖。
- 兩層決策的 AI 呼叫觸發與用量限制。
