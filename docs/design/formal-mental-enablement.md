# 正式精神電量啟用（#263）

依據 #255、#263、#271 已批准契約 D 與 [#256正式政策](formal-mental-energy-policy.md)。本文件是應用入口契約；容量分布、五階段、時間格、成果骰、過程骰及五點調節成本沿 #256，不另外建立政策或測試預設。

## 真正初始化與明示採用

新城市草稿可為人物提供 `mentalOpening`：`capacity`（明示正整數）、`minimum/maximum`（背景限定一般容量範圍）、`current`（明示非負整數）、`stage`。未指定沿正式建角及七成開局規則。預覽只驗證，真正 `start-city` 成功寫入時才呼叫 `createFormalMentalEnergy`，並初始化 `five-minute-v1`。失敗不發佈人物，原 operation ID 讀回不重新形成容量。

一般容量支持集仍為原有 40、45…90 與原權重；範圍只依明示背景限制。精確目前電量／階段必須對宣告支持集的每個容量都合法，否則保留草稿並提示指定固定容量或收緊背景範圍，抽樣前停止。例：未指定容量但 `current:80` 不合法；明示 80–90 與目前80合法，保留原條件權重；60–90／目前40／尚可因部分容量階段不同而拒絕。不依目前電量偷偷篩容量，也不以重試挑容量。65／目前3／充沛矛盾；65／有餘形成46。

相容舊世界在角色卡明示提交 `enable-mental-energy`／`mentalOpenings:[{id,opening?}]`。完整驗證於租約／抽樣前進行；成功保存當前分鐘為啟用點，不補心理歷史，並明示採用五分鐘時間契約。尚未相容的追求契約沿原 gate 拒絕。只有缺欄位或 undefined 可建新狀態；null、空物件、未知政策、損壞正式狀態一律拒絕。已有合法正式狀態透過 `assertFormalMentalEnergy` 只讀驗證，無新 opening 時原樣保留容量、seed、coverage、來源收據、歷史及 pending；有新 opening 不容許重建。

測試政策不得轉正式，正式入口不接受 seed、速度、費用等工程旋鈕；production 連既存測試政策亦拒絕推進。普通 GET 不驗證後改寫、不啟用、不抽骰；壞資料畫面顯示不可用及既有相容處置，API 仍 fail closed。

## 實際生活及觀察

正式狀態接既有世界時間、活動、可知經歷、真正成果、自主調節與受控感受流程。身體先結算已發生醒點，精神只結算已發生有效格，不預抽未來。純續做、GET、reload、原 ID 不新增決策或感受呼叫。控制權切換不替換使用者行動，不額外扣調節費。所有效果、來源消耗、心情及精神資料沿同一 CAS 提交；用量仍沿既有 known/unknown/late 契約。

角色卡以公開只讀 validator 保護壞正式狀態。模型只看本人階段、能否支付及合法可知來源，不看精確數值、policy、seed、骰果或觀察者資料。卡片列每顆骰面／原始收支、同組整體 before→after 及上下界截斷；同格各來源不被分配虛構的個別實際截斷。固定睡眠回電不冒稱骰果；無影響不擲骰；心理努力、心情前後另列。工程容量只在開局背景設定出現，平常生活不提供改寫入口。

驗收與故障矩陣見 [#263驗證](../verification/formal-mental-enable-263.md)。受控模型僅證明契約承接及記帳，沒有證明真實模型的心理語義品質；沒有授權付費、部署或推進正式世界。
