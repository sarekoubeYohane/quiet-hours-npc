## 推薦 A：五級人物與有限 d100 映射（#272）

四屬性採 1–5 整數，3 為一般。未指定時各獨立抽 `2d3−1`，機率依序 `1/9、2/9、3/9、2/9、1/9`。背景明示固定值或合法區間；直接依原分布在區間內條件抽樣，不反覆重抽。合法精確值優先；互相矛盾、空區間或超出背景者保留草稿並拒絕開始／啟用，不默默夾值。自由文字的限制先在既有可編輯初始化草稿呈現供核對，不以角色名、職業或關鍵字表猜成權威數字。

每次合法不確定嘗試只取一項相關基本屬性；無關四屬性的嘗試可不取。成功門檻：

`T = clamp(55 + (屬性−3)×10 + 難度 + 領域專長 + 感官特性 + 關注, 10, 75)`。

難度容易／一般／困難 = +20／0／−20；領域專長與感官特性各最多取一個已保存有效等級（−20／−10／0／+10／+20）；主動專注／普通／分心 = +10／0／−10。無相關屬性時該項修正為 0。同一事實只進一類：已降低屬性的同一弱點不可再扣特性；噪音歸環境難度，聽力條件歸感官，不能重扣。絕對無機會先排除，不能以大成功突破。

專長／感官的數值權威只能來自擁有者已明示確認的既有設定，或既有可編輯人物草稿中明示列出的適用範圍與五級修正，經擁有者確認後隨成功開始／導入寫入才生效；草稿的自由文字候選未確認前不能取得權威。沒有已確認數字時該項採 0，不從角色名、職業詞或未定敘述任意推成 +10／+20，也不由每次裁定臨時重定級。沒有數字不移除已確認的失明等感官硬限制，硬限制仍先判斷感知機會。

| 骰點 | 結果 |
|---|---|
| 01–05 | 大成功 |
| 06–T | 成功 |
| T+1–T+20 | 部分成功 |
| T+21–95 | 失敗（T=75 時此段為空） |
| 96–100 | 大失敗 |

取捨：五級足夠呈現穩定差異，固定 20 點部分成功帶能沿用現有五段分支；最好情況仍有 20% 部分成功與 5% 大失敗，高手不保證完整成果。這是新推薦，並非 CoC 半值／五分之一規則。

算例：一般難度、無專長，靈巧 2 的 T=45，骰 50 是部分成功；靈巧 4 的 T=65，同骰成功。T=55 時，1/5 大成功、6/55 成功、56/75 部分成功、76/95 失敗、96/100 大失敗。失明者沒有視覺機會，清楚直接可見則直接察覺，兩者均不擲骰。

舊人物缺值只在擁有者明示導入的成功寫入中形成，不在 GET 補值。舊 D20 結果／活動／規則維持原版；新制度只適用新機會及新確認規則。跨版本先找同方法、同實質條件的既存結果，有結果便沿用，不能以新能力欄位或版本改變 trial key 重抽；已有精神容量維持唯一來源。未啟用人物資料不強制切換 d100。

## 推薦 B：五分鐘步進，保留活動耗時尺度（#273）

每個世界寫入步驟推進 5 分鐘；活動目前的 15 分鐘完成／開放時段尺度先保留，既有已確認耗時不縮短。新活動從取得本次選擇的邊界向後開始，停止把它倒填到剛經過的時間。短動作也必須真正經過已定活動時間才取得其後果；路程保留原有獨立耗時。

UI 的 15／30 分鐘快轉成為 3／6 個五分鐘原子操作的序列。每步各自遵守原 operation ID、CAS、預算、期限及用量；失敗停止並保留已提交前步，原 ID 查證後才繼續。已受理舊操作保持精確回放。長活動只有原本合法決策機會才叫模型，不逐步重新選擇。

取捨：保住現有活動平衡與單次請求容量；代價是喝水等既有最短動作仍耗 15 分鐘，第一次推進可能只取得新選擇，快轉也改為可部分完成。未選普遍縮短所有活動或一次 HTTP 包六輪。

格內事件／舊活動及既有睡眠的精確自然醒保留實際時刻（新正式睡眠的格末醒法見推薦 C）；下一正常五分鐘提交點提供本人可知結果及一次合法重新考慮機會，不提前提供線索。睡醒後的剩餘時間按清醒身體需求計，新選擇不能倒用睡前時間。原技術睡眠區段到期不表示自然醒。

算例：t0 已開始 15 分鐘活動，t5/t10 無完整成果，t15 才完成；若 t5 才選，t20 才完成。60 分鐘活動在 t15/t30/t60 的階段各一次，純續做無新增呼叫。既有舊睡眠於格內 t7 醒來，t7..t10 仍依舊需求規則計清醒，t10 才能依新可知狀態選行動；不以新骰改寫 t7。UI 快轉30與手按六次5在同受控來源下相同；第三步後故障保留 t15。舊世界若目前127，下一步132才交付名義130的階段，保留 nominal/committed 區別，不改寫舊時刻。

## 推薦 C：三項需求特性、有限時間擾動（#274）

飢餓、口渴、清醒睡意累積各保存一項特性，一般各由公平 d6 的 1–2／3–4／5–6 取 0.8／1／1.2；背景可指定固定值或合法子集。疲勞先沿既有明示 `bodyActivity` 負荷，**不增加第四個需求體質或提前套用未交付耐力**。因此 #278 不新增 #275／#277 前置。

新正式規則推薦採用現有工程基線的 0–100 範圍、40/65/85 感受門檻及未指定初值（餓20／渴20／累15／睏20）；此處是請求批准這些值，不宣稱歷史 fixture 已批准。合法精確初值優先；只指定感受時用該區間中點 20／52.5／75／92.5，明示完全無需求／極限為0／100。開局文字與數字矛盾時在草稿解決，日常文字不反向重設。既有世界保存目前需求，只新增未有特性，不補算歷史；若人物正在既有睡眠，依下述分階段啟用方式延後切換，不混用新舊規則。

另行推薦身體時間也用絕對五分鐘格（不是由精神規則推定）。每角色／需求／新格公平 d6 取 0.8／1／1.2 的時間係數，同格重送／分段／重載沿用。每時基線餓3／渴6／累1／睏4；餓渴與清醒睡意先乘個人特性，再乘本格係數。疲勞將基線與既有活動額外後果合成後乘本格係數；清醒休息不降低睡意。實睡時睡意使用既有普通基準淨恢復 `(4 + sleepPerHour)` 乘睡意時間係數，不另疊個人清醒累積；疲勞 `(1 + fatiguePerHour)` 同理。餓渴在睡眠中照常累積。

實際攝取仍沿原物件消耗與已確認份量的 hungerRelief／thirstRelief，沒有再骰一次物件恢復值。時間正負幅度有 ±20% 擾動，不把負恢復翻成增加需求；同一需求同刻時間來源先合成再裁切。內部精確累計、畫面兩位小數，不能逐格取兩位造成漂移。

新正式身體政策的 off-grid 起訖按真實覆蓋分鐘積分，使用本格已取係數，不預領、不移動事實時間；身體需求不要求全格覆蓋，**不套用推薦 D 的精神電量完整格規則**。既有活動的已確認後果與時間保留，但正在延續的舊睡眠為整段舊政策例外，見下段啟用程序。引擎可在舊15/30 API內逐五分鐘結算新政策身體時間，因此不必新增 #276 前置。新格才取骰，不逐格呼叫模型。

新正式睡眠採「已經發生的恢復使睡意首次到20以下／等於20」作為醒來條件；逐個絕對五分鐘格末檢查並保留實際值，不預抽未來骰、不倒推格內穿越點或預報權威醒點。新正式睡眠若於 off-grid 時刻開始，首段按到下一格末的真實分鐘積分並在該格末檢查；例如08:02開始，08:05先結算三分鐘，不能算成五分鐘。技術區段可依現行上限續接，不當作醒來理由；在最慢恢復下界也無法於既有合法上界內成立的候選沿原確認失敗契約處理。

推薦的現行需求啟用程序：擁有者明示導入後，在成功的可寫操作記錄各人物政策版本與起點，GET不啟用。清醒人物從該起點向後使用新特性與時間骰，既存需求值不重算；正在睡眠的 legacy 人物則保留整套原需求時間規則、已確認恢復曲線及精確自然醒／刺激醒處理，直到該既有睡眠真正結束，期間不抽新需求骰、不套新特性、不改寫已有醒點。從醒點到當次提交點的剩餘時間也沿舊規則結算，至該次正常提交點才啟用新政策；之後新開始的正式活動才用新骰。各人物可以有不同啟用起點，版本與待啟用狀態隨同一世界候選原子保存，失敗不留下半切換；不得為統一全員版本而中止睡眠或補算新政策歷史。

取捨：三項特性與小幅擾動提供差異，仍保留既有活動／物件權威；本期疲勞不由耐力自動個人化，食物／飲料的已定恢復也不再隨機。新正式睡眠的自然醒由實際恢復決定，不能入睡就知道未來醒點；既有 legacy 睡眠保留原精確醒法至結束，接受分人物延後啟用的相容成本。

## 推薦 D：精神電量剩餘契約（#256）

**以下是本次明確提出的新推薦，包括 Q30 的候選；等待本次批准才生效。**

1. 固定世界五分鐘格採完整覆蓋：自然耗電須全格清醒，實睡單位須全格實睡，持續來源須全格成立；只在格結束結算。混合睡醒格不算清醒自然骰或實睡單位；格內開始／結束／改感受的來源當格無完整效果，下一完整成立格才有效。不中途比例計費、不挪事件時間；同來源技術切分不破壞完整覆蓋，真實中斷則破壞。未滿一小時的完整實睡單位持續保留。
2. 同一邊界先處理剛經過時間：自然／持續來源及恰累積滿12個實睡單位的固定+1合成，裁切一次。再處理此刻實際評價成立的一次性感受：無因果先後的同刻正負來源合成後裁切一次；真有先後者按事實順序各處理，不按陣列順序湊額度。最後才核對自主調節5點。晚評價的合法來源從本次評價時刻結算，不倒填過去。
3. 特殊容量允許背景明示正整數固定值，或一般公式支持集內的上下限；區間依一般分布條件抽樣，不改成均勻、不反覆重骰。只有範圍落在一般支持集外時要求明示固定特殊容量。精確目前值限0..容量整數，小數在草稿拒絕並保留原輸入，不偷偷四捨五入；比例初值仍半點進位。互相矛盾的開局資料先修正，不以心情推電量。
4. 新世界在既有初始化開始時形成容量／目前值；相容舊世界以既有畫面明示一次啟用及其起點，缺容量才依確認背景抽取，合法既存正式容量／目前值沿用。GET不變、失敗不留下半啟用、其他版本 gate 保留。隔離 test policy 不轉成正式容量或收益，production維持拒絕；需另以相容的未啟用世界承接，不能把fixture數字洗成產品資料。

取捨：完整格容易核對、沒有隱藏小數或未來收入，但每次真實格內變動會失去不足完整格的收支（混合睡醒格自然消耗與實睡回電進度均不計）；這是需批准的產品代價，不是工程預設。先時間、後事件會讓時間溢出先丟失；同刻無序一次性合計則避免列舉順序改變裁切。

算例：容量65、原64，完整格持續+3／自然−1→65，此刻獨立消息−4→61，自主調節→56；若將跨組全部混算會多留1點，故不採。原64、同刻無序一次性+3／−4合計→63；有已知先後+3後−4則65→61。08:02開始享受、08:12結束，僅08:05..08:10是完整有效格；08:02..05及10..12不補。原規格的睡55分鐘後清醒、再睡5分鐘累積回1例，在本推薦中另假設兩段均完整格對齊，才等於12個完整單位；這個對齊是假設，不是原算例已批准的限制。08:02..08:57這段實睡只有10個完整格，零碎分鐘不冒充55分鐘有效進度。
