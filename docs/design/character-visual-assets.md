# 角色圖像接點

`lib/character-assets.ts` 以世界的穩定角色 ID 分別對應 `pixel`（地圖／輕量身份）及 `portrait`（人物檔案）。頁面不依顯示名稱推導檔名；未知 ID、人物圖載入失敗以名字首字及明確替代文字顯示，狀態與互動保持可用。

目前 #90 沿用既有可辨識人物素材，並未生成新圖或修改人物設定。簡介直接取自保存世界的 `personality`；當前狀態直接取自同一世界快照，不補寫生活經歷。

| --- | --- | --- | --- |
| cass | `/pixel/cass.png` | 227 × 593 | 既有單幅像素人物 |

人物檔案以 contain 顯示完整人物，桌機高 400px、窄畫面高 300px，維持既有像素邊緣；不把這次放大顯示宣稱為 #88 的新高精細素材。#88 可直接替換各 ID 的 `portrait`／`pixel` 路徑及 `source`，保留其他用途；不需改世界、重置世界或新建 UI。新素材品質、各用途尺寸、透明及幀資訊仍由 #88 交付與驗收。
