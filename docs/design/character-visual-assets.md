## 可載入檔案

每位存於 `public/characters/<id>/`，URL 為 `/characters/<id>/…`；四位同規格。

| 用途／檔名 | 尺寸 | 格式／透明 | 接入位置 |
| --- | --- | --- | --- |
| `master.webp` | 1024×1536 | WebP quality 95；不透明象牙白背景 | 全尺寸定妝參考；選定生成 PNG 全解析轉碼，非無損原 PNG |
| `portrait.webp` | 768×1152 | WebP quality 90；不透明 | 已接入人物檔案，contain，桌機高 400px／窄畫面 300px，平滑縮放 |
| `avatar.webp` | 256×256 | WebP quality 92；不透明 | 同主圖裁切；清單提供，對照頁 80px 展示。既有輕量面板仍沿像素身份元件 |
| `idle.png` | 48×96 | PNG RGBA；二值 alpha | 已接入地圖與輕量面板，最近鄰縮放；未知 ID／失敗沿首字 fallback |

機器可讀欄位、URL、生成輸出 ID 見 [manifest](../../public/characters/manifest.json)，是載入接點的同一份來源。沒有第二套角色 UI 或地圖引擎。

每位小人 **1格、1欄、1列、前／微側站姿待機**，全圖即單幀，最後不透明列 y=91、腳底基準邊界 y=92、底留4px。四周透明留白。現有移動／活動沿站姿及既有 CSS 動態，不宣稱方向或走路動畫；合法活動不需專屬素材。

prompt 要求 logical 32×48，工具實際回傳 1024×1536 像素風圖，不能宣稱原生格網精確符合要求。交付單幀經 alpha 90% 二值清理去暈邊、裁切、最近鄰縮入40×88，再對齊48×96畫布。不是把平滑主視覺縮小冒充像素。PNG 不含背景陰影，陰影由地圖元件提供。

## 設定與生成來源

優先級：本輪明確外觀選擇 > 現行人物核心對身份／人格的約束 > 經本輪挑選的 legacy 外觀 > 舊觀察室測試圖。舊銀髮藍衣 Vera、短髮 Kris 已被本輪選擇取代。未混入 Rhaelyth，未修改小說 repo、世界種子、性格、經歷或用量。

已核對 story-writing 的 README、AGENTS、寫作協作規則、故事核心、現行三位 core、Vera 生活方向及三份 legacy JSON。來源 Git blob SHA、完整實際提示詞與工具資訊見 [生成記錄](character-generation-2026-10-16.json)。legacy 的健康／量子手環／照護／社會限制等敘事前提未整包回收。三張參考不打包進產品，保留檔名與 SHA-256。工具未提供 seed 與精確模型版本，記錄為未知。

## 檢視與重現

- `/characters/preview.html` 提供逐角色主圖／頭像／原生48×96／代表桌機30×60與窄畫面約17×33小人對照，連到全解析主圖。
- [匯出腳本](../../tooling/verification/prepare-character-assets.py) 使用 ImageMagick，輸入原始 generated_images 目錄；無模型呼叫。實際交付檔案皆可在 repo 載入，不依賴臨時圖片網址。
- [瀏覽器驗證](../../tooling/verification/browser88.mjs) 驗證所有圖片解碼、尺寸、透明、基準線、四位正式檔案頁與地圖、縮放、窄畫面及世界不變。
- 全身主圖比例仍略修長，不能以圖反推精確身高。地圖小尺寸依髮型／服裝色塊辨識，不呈現完整指節／頸側細節。僅交付一幀基本待機，不含住宅場景或全動作動畫。
