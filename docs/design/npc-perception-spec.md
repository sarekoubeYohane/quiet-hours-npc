## Problem Statement

目前角色的現場知情範圍主要依是否位於同一場所判斷，缺少隔間、門、視線、聲音傳遞及角色注意力的差異。觀察行動尚不能提供完整的查探與取得線索流程。使用者難以觀察「同一件事，不同角色注意到不同內容」及其後續反應，也難以分辨世界真相與角色主觀感受。

感知若每次都呼叫模型、每個感官都重複擲骰，或任何新資訊都打斷活動，會增加成本並破壞角色持續生活。另一方面，單純將大失敗視為沒有收穫，無法呈現使用者希望的誤聽、誤看及沒有對應外在刺激的主觀感受。

## Solution

以咖啡館前台、儲藏室及兩區之間的門，建立可替換的視覺／聽覺 PoC。世界先確認事件與場景狀態，再由程式依位置及環境判斷各角色的感知機會。明顯線索直接察覺，不確定線索則每個角色、每次有效機會綜合判定一次，沿用既有 D20。

角色取得帶時間與可知來源的主觀觀察。大失敗可產生錯誤感知，由角色期待與情境調整合理候選的權重後隨機選取；沒有合適候選時可沒有新收穫。錯誤感知不改變真實世界，但可照常觸發關注及活動中斷。

角色在既有決策中同時提供簡單關注條件。程式比對主觀線索，讓一般資訊等待下一次正常決策；值得立即回應的資訊可中斷活動。每個 NPC 每輪世界推進最多一次模型行動決策，包含突發危險。使用者可展開感知詳情查看差異、骰子與影響因素。

## User Stories

1. 作為觀察者，我希望同一事件對不同角色產生不同的感知結果，以觀察角色各自的知情範圍。
2. 作為觀察者，我希望門與隔間能遮擋視線，以避免角色直接知道看不見的事情。
3. 作為觀察者，我希望聲音能依門與噪音傳遞，以呈現只聽到動靜的情境。
4. 作為觀察者，我希望明顯資訊直接被察覺，以免清楚可見的事情因額外骰子而消失。
5. 作為觀察者，我希望不確定線索有統一的 D20 判定，以理解角色為何注意到不同程度的資訊。
6. 作為觀察者，我希望同次機會綜合視覺與聽覺，以避免重複擲骰與重複結果。
7. 作為觀察者，我希望角色的感知專長與弱點只在相關情境生效，以保持角色差異的合理性。
8. 作為觀察者，我希望角色性格、意圖與手上活動影響留意方向，以呈現有目的的注意力。
9. 作為 NPC，我希望只取得當時可接觸的線索，以依自己的經驗作出選擇。
10. 作為 NPC，我希望聽到未知腳步時能保留來源未知，以免系統直接替我辨識來者。
11. 作為 NPC，我希望部分成功只提供片段或模糊內容，以便自行判斷是否查探。
12. 作為 NPC，我希望普通失敗不提示我錯過了事件，以免因判定資訊取得額外知識。
13. 作為 NPC，我希望主動查探無收穫時能知道沒聽清或沒有新線索，以理解自己剛做過的事。
14. 作為觀察者，我希望大失敗能產生誤聽或誤看，以觀察錯誤感知如何影響生活。
15. 作為觀察者，我希望大失敗也能產生沒有對應刺激的主觀感受，以呈現另一類錯誤感知。
16. 作為觀察者，我希望錯誤內容受角色期待與情境影響並保有隨機性，以避免每次都出現同一種誤會。
17. 作為觀察者，我希望無合適候選時不強迫製造錯覺，以維持場景合理性。
18. 作為 NPC，我希望依自己的主觀感受觸發關注，以便對誤以為有人呼喚的情境作出自然反應。
19. 作為 NPC，我希望察覺資訊後仍能選擇繼續、暫停或改變活動，以保留自主性。
20. 作為觀察者，我希望一般資訊不立即打斷所有角色，以維持持續活動與模型成本。
21. 作為觀察者，我希望重要突發刺激能越過預先關注條件，以避免角色完全忽略已察覺的急迫情境。
22. 作為觀察者，我希望每個角色每輪最多一次模型決策，以控制事件引起的連鎖成本。
23. 作為 NPC，我希望本輪決策後取得的線索保留至下次使用，以免較晚的事件被丟失。
24. 作為 NPC，我希望可透過移動、開門或主動查探取得新的有效機會，以逐步了解環境。
25. 作為觀察者，我希望相同條件與重新載入不重擲，也不重新抽錯誤內容，以保持結果一致。
26. 作為 NPC，我希望舊觀察保留時間與來源，以區分先前看到的事情與當前已確認的狀態。
27. 作為接管中的使用者，我希望店主仍照常感知且由我選擇行動，以保留控制權。
28. 作為觀察者，我希望交還控制後角色使用接管期間的主觀觀察，以延續經歷。
29. 作為觀察者，我希望展開詳情能區分無感知機會、未察覺、部分察覺及錯誤感知，以理解結果。
30. 作為觀察者，我希望詳情直接呈現已有紀錄，以避免額外生成說明的模型費用。
31. 作為 NPC，我希望決策輸入不含觀察者診斷資訊，以避免透過骰子、隱藏身分或錯誤標記得知真相。
32. 作為使用者，我希望咖啡館 PoC 可在未來更換格局，以配合已規劃的地圖大更新。
33. 作為既有世界的使用者，我希望載入舊存檔能取得安全預設，以繼續試玩且不突然補發未曾察覺的歷史事件。

## Implementation Decisions

### 1. 範圍與模組責任

- 感知模組處理機會、主觀結果、觀察保存及觀察者診斷；世界行動裁定提供可信事件與場景變更；活動排程依主觀資訊決定是否需要既有決策；模型介面輸入主觀資料並輸出關注條件；介面呈現簡潔敘事與可展開詳情。
- 只加入驗證所需的區域移動、開關門、主動查看／聆聽接點。世界驗證操作結果後才更新場景，不以自由文字直接改門或位置。
- 咖啡館採前台、儲藏室與一扇連通門；其餘既有場所先使用單區域。場所設定與感知規則分離，不把咖啡館名稱或固定房間數寫死於規則。
- 事件、進入區域、有效主動查探與影響當前可接觸線索的場景變化觸發感知。只處理相關區域角色；不設每秒全世界掃描或背景錯覺排程。
- 私密內心、私人訊息及觀察者對指定角色的介入沿用既有知情通道，不因感官系統擴大受眾。

### 2. 場景與操作的最小契約

- 世界保存區域歸屬、連通關係、門開關、噪音與必要遮擋。動態條件僅由已確認行動或明確世界事件更新。
- 模型只能取得角色可知的場景內容與合法操作目標，不提供完整隱藏場景圖或未察覺的動態狀態。
- PoC 的規格化預設為：舊咖啡館角色置於前台，門初始開啟，未指定噪音或遮擋時採一般安靜且無額外遮擋；其他場所使用其單一預設區域。既有歷史不重新分發或補骰。
- 移動、開關門是一次性行動，依既有世界推進節奏執行；關閉的門需先打開才可通過。主動查看／聆聽沿用觀察行動與既有活動時間選項。
- 輕度留意透過活動中的關注條件表達；需要移動或專注的查探使用行動機會、調整原活動並經過世界時間。持續觀察不代表每輪可重擲。
- 話語、腳步、門聲與人物輪廓等線索由世界確認的事件建立。噪音與遮擋先由場景設定及明確事件提供，不建造物件互動系統或環境編輯器。

### 3. 感知機會與 D20 結果

- 先判斷感官是否能接觸線索，再判斷是否明顯。沒有機會的感官不擲骰、不提供其隱藏資訊；可以聽到的事件不因此取得視覺資訊。
- 直接察覺的內容與不確定內容分開保存。同一機會的不確定部分綜合擲骰一次，不能因失敗撤回已直接察覺的內容。
- 使用既有難度 8／12／16、修正值 −4／−2／0／2／4 與五級結果。沿用既有差額門檻，不增加自然 1／20 的特殊規則。
- 客觀傳遞條件影響難度；相關能力與當下注意力影響修正。相同因素只計一次，單純喜歡某人不等於擅長辨識聲音。
- 具體映射採可替換設定。PoC 預設：清楚同區人物及安靜環境下清楚話語直接察覺；門關閉阻擋跨區視覺；隔門普通語音可僅提供模糊聲響，不能將成功當成逐字聽清；明顯強聲可直接聽到聲響，但來源與內容仍可能未知。
- 不確定線索依弱／中／強干擾使用 DC 8／12／16；若根本無法傳達，視為無機會而非高難度。多感官對同一內容互補時採較有利的有效條件，仍只產生一次判定，輸出內容逐項受可接觸範圍限制。
- 規格化預設：沿用相關能力標籤的受控對照，未配置或無關能力為 0；不由模型當場發明角色能力。有效專注觀察可提供 +2，與線索爭奪注意力的投入活動可提供 −2，與相關能力合計後限制在既有修正範圍；情境標記由明確活動類型／觀察目標決定。
- 以上預設是本次規格化方案，可在實作前依測試案例調整設定；任何調整不得改變已確認的資訊邊界或新增產品系統。

| 判定結果 | 主觀輸出 |
| --- | --- |
| 大成功 | 取得設定中可接觸的最清楚線索；無額外可得細節時可與成功相同 |
| 成功 | 取得清楚但受感官條件限制的線索 |
| 部分成功 | 取得片段、模糊或未辨識來源的線索 |
| 失敗 | 沒有新線索；主動觀察可回報無收穫 |
| 大失敗 | 依適用候選產生錯誤感知；無合適候選時沒有新線索 |

### 4. 主觀內容、錯誤感知與真實世界

- 主觀內容包括觀察時間、感官、內容類型、清晰程度與角色當時可知來源。未辨識來源不得直接帶入真實演員身分、真實位置或原因。
- 世界內部另外保留判定、真實事件關聯及錯誤類型，供診斷與重試去重使用；這些資料不進入 NPC 上下文。
- 大失敗允許兩類候選：扭曲現場線索，以及沒有對應外在刺激的主觀感受。兩者皆由當次不確定判定觸發；沒有任何有效機會時不另外擲骰產生錯覺。
- 候選採少量可設定模板。先依感官、情境與角色已表達的期待／關注條件篩選，再加權隨機；相關候選優先、其他合理候選仍有機會。PoC 可採相關候選權重 3、其他適用候選權重 1 作為明示預設。
- 候選不能讀取角色未知的真實身分來挑選假身分。誤認熟人只能取自角色本來認識或期待的人；誤聽內容不複製實際未能聽清的私人話語。
- 沒有合適候選就沒有新收穫，不強制通用錯覺。已清楚察覺的事實不被另一部分的大失敗追溯抹除。
- 錯誤感知可以讓角色主觀以為辨識某人，並以該主觀身分匹配關注條件。這是本次後續決定對早期「未知保持未知」的補充；判斷仍不能直接使用隱藏世界身分。
- 錯誤感知不建立真實人物、物件或事件，不強制信念確信程度與後續行動。角色收到主觀內容，不收到「這是錯誤」或「大失敗」標記。

### 5. 關注條件、意圖與決策成本

- 沿用既有意圖佇列；關注條件附在同次模型決策，不增加獨立待評估事件佇列。
- PoC 關注條件只含有限的線索類型，以及可選的角色已知對象／區域目標；同一條件的欄位需同時符合，多條件任一符合即可觸發。初期限制最多 12 條，與既有意圖數量界限一致。
- 線索類型先涵蓋人物進出／靠近、說話或直接呼喚、一般聲響、門狀態變化。條件的目標須來自角色可知資料；不支援自由程式、任意世界查詢或隱藏身分條件。
- 模型格式不合法沿用既有失敗處理，不新增重試呼叫；單條條件有未知類型或越界目標時捨棄該條，保留其餘有效決策，觀察者可看到診斷。遺失新欄位的舊世界預設空條件。
- 比對對象為主觀內容，包含錯誤感知。一般線索保存後等下次決策；符合關注條件的線索可提前評估。已察覺的明顯危險、強刺激或對自己的直接互動可以越過預先條件。
- 重要性標記只能依角色取得的內容判斷，不能用事件隱藏原因判危險，也不能因內部知道其為錯誤就抑制反應。
- 需要決策時，角色以性格、意圖優先順序、活動進度及主觀觀察選擇續做、暫停或改做。提前評估不保證切換行動。
- 每個 NPC 每輪世界推進最多一次模型行動決策。該角色已決策後才到達的資訊，即使重大危險，也留至下一輪。感知本身照常執行。
- 基本場景規則、擲骰、關注比對、錯誤候選與詳情皆由程式處理，不逐事件呼叫模型。仍沿用現有模型預算與失敗回復規則。

### 6. 有效機會、保存與舊世界相容

- 機會依角色、線索／事件，以及會改變可接觸內容或有效注意方式的條件識別；全世界回合數、重新載入、無關門的變化不構成新機會。
- 換位置、有效改變觀察方向／方式、靠近聆聽或新增可接觸線索可形成新機會。原線索已消失時不能對舊聲音重試。
- 相同事件與相同有效條件沿用結果；重複提交相同觀察、只換文字描述或來回切換至已處理條件不得刷骰。
- 隨世界保存原始主觀觀察、內部機會識別與結果（含抽中的錯誤內容）、角色決策已處理進度。較晚到達且未使用的觀察不得被目前最近記憶截斷策略丟掉。
- 原觀察代表當時的感受，不隨未察覺世界變化自動更新或標記失效。世界內部真實事件 ID 不作為 NPC 可解讀的來源資料。
- 主觀觀察進入模型、既有記憶與接管經歷的任何通道，都不能混入全知事件原文。已知來源、部分內容與錯誤感知的處理必須一致。
- 舊存檔補足最小場景與感知容器，保留既有歷史但不反推舊事件的新感知結果，不因首次載入補擲骰或補發隱藏資訊。
- 世界狀態、觀察與處理進度一起提交，沿用既有鎖定、版本檢查與回合失敗回復。已提交的結果不得因讀取重抽；未提交的失敗回合不留下半套觀察。原有已付模型用量紀錄仍須保留。
- 去重資料若需清理，至少保留仍可查探的線索及未完成決策使用的觀察；不能因清理造成同次機會重擲。

### 7. 接管與使用者介面

- 接管、待命與指定活動中的角色照常感知和保存觀察，動作由使用者決定。交還後以這些主觀經歷重新評估，不補發全部世界真相。
- 沿用現有敘事與接管操作介面，加入 PoC 必要操作及區域／門的簡潔呈現；不製作新地圖編輯或大型視覺重構。
- 使用者可展開事件／觀察詳情，查看各角色是否有機會、實際取得內容與清晰程度、是否為錯誤感知、骰子結果及關鍵條件。
- 無機會與有機會但未察覺須分開顯示；錯誤感知能呈現主觀內容與世界情況的差異。
- 詳情直接讀取既有診斷，不額外要求模型生成說明。觀察者可見的資料不代表 NPC 可見。

## Testing Decisions

測試入口：以既有世界操作 API 為主要行為驗收入口，搭配既有模型服務替身檢查實際送出的角色上下文；少量畫面驗收確認接管操作與展開詳情。使用者於 2026-10-10 要求進入 to-tickets，沿用此測試方案。

- 好的測試從世界操作進入，檢查保存後的主觀結果、行為、模型請求與呼叫次數；不以內部函式呼叫順序、資料結構快照或私有輔助函式作主要斷言。
- 沿用現有 D20 API、持續活動、接管與儲存衝突測試的方式：使用暫存世界資料庫、固定亂數與模型回應替身。感知新增結果可從相同入口驗證，不另建公開骰子控制端點或獨立測試管理系統。
- 覆蓋模組包括世界裁定與感知、活動排程、模型上下文投影及存取保存；多數案例透過同一 API 操作流程涵蓋。
- 攔截真實模型請求邊界，驗證不可知資訊不進入輸入；不依真實模型隨機回覆判斷測試成功。
- 測試應驗證以下外部行為：

| 情境 | 驗收結果 |
| --- | --- |
| 同區清楚人物／話語 | 直接察覺，不擲骰；其他部分失敗不撤回它 |
| 門關閉、跨區事件 | 視覺無機會；聽覺依可傳遞程度提供有限內容 |
| 同次視覺＋聽覺不確定 | 每角色只進行一次感知骰子判定，結果不越過各感官資訊上限 |
| 固定各級骰子結果 | 五級輸出符合表列映射，能力與注意力只影響相關判定 |
| 等 Vera、僅有未知腳步 | 未辨識前不以真實事件身分匹配 Vera |
| 大失敗的兩類候選 | 可得到扭曲線索與無對應刺激內容；真實世界不被創造或修改 |
| 情境與隨機性 | 固定亂數可重現結果；相關候選權重較高，其他適用候選仍能被選中 |
| 沒有適用候選 | 保留大失敗診斷，但沒有新主觀線索 |
| 錯誤感知符合關注條件 | 可促使既有決策入口評估，未強制具體動作 |
| 普通無關線索 | 保存但不中斷；下一次正常決策能取得 |
| 強刺激／直接互動 | 已感知時可越過關注條件；未感知時不能靠隱藏真相觸發 |
| 同輪多事件及晚到危險 | 每個 NPC 最多一次模型行動決策；晚到觀察留到後續決策 |
| 重載與相同條件重試 | 不增加骰子或錯誤候選抽選，不重複觀察 |
| 有效查探與已消失線索 | 前者取得新機會；後者不能重聽已不存在的聲音 |
| 接管與交還 | 感知持續保存，由使用者操作；交還不補發未知事件 |
| NPC 模型輸入 | 無真實隱藏來源、其他角色私密資訊、骰子、DC 或錯誤診斷標記 |
| 舊觀察與未察覺變化 | 舊內容不被全知狀態即時改寫，時間與來源仍保留 |
| 舊世界載入 | 可繼續使用，無歷史補骰或新增全知經歷 |
| 模型失敗／保存衝突 | 世界、觀察及進度保持一致，不提交半套結果，保留既有用量規則 |
| 畫面展開與接管操作 | 使用者能辨識感知差異並操作最小 PoC，詳情不增加模型呼叫 |

- 固定亂數用於可重現的邊界案例，不以不穩定的大量抽樣驗證機率。
- 實作時執行相關 API 測試及既有必要檢查。畫面驗收只涵蓋新增操作與感知詳情，避免為此擴建端對端測試平台。
- 本次僅產出規格，未宣稱上述功能或測試已實作通過。

## Out of Scope

- Memory & Belief 的長期記憶分類／選取、信念確信程度、來源信任、認知修正與舊記憶更正連結。
- 完整地圖重做、所有場所多區域化、精確座標視線與聲學模擬。
- 嗅覺及其他感官、每秒全世界感知掃描、獨立錯覺排程。
- 完整移動／門／物件互動系統、物理模擬、環境編輯器或新的行動裁定規則。
- 角色能力養成或自動生成感知專長、通用任意條件語言。
- 每次感知額外模型呼叫、同輪緊急第二次模型行動決策、獨立待評估事件佇列。
- 背景自動推進排程、帳號／Key／部署等 Infra 工作。
- 本規格發布本身不包含程式實作；工作拆分另依 to-tickets 進行。
