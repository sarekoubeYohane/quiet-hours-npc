# 自然變化的離散提交時間

狀態：#150 的工程時間方案已確認；實作／驗證結果由對應驗證文件記錄。

自然變化從已形成且正式提交的外在狀態延續，不是角色的新選擇。模型在同一次有界裁定確認延遲、必要持續條件及外在狀態後果；解析不建立安排，只有選中分支的正式效果批次能保存安排。執行不再詢問模型或擲骰。

## 時間與順序

既有世界每次推進15或30分鐘，先到回合終點，再依角色順序決定續做、中斷或新活動；當回合活動階段的世界效果與事件時間都在該提交點結算。活動的 `startedAt`、`until` 與 `afterMinutes` 仍表示模型確認的投入與進展時間，不能由這些資料補造過去已提交的效果。

新安排保存實際提交時間 `committedAt`，到期時間為 `committedAt + delayMinutes`。必要時另列來源階段的 `nominalDueAt`，區分活動已具足進展的時刻與外在效果真正保存的時刻。模型確認15分鐘仍是15分鐘；一次推進30分鐘只在該次離散結算時看到成果，不將耗時改寫為30，也不追溯觸發剛建立的自然安排。

每次推進先依到期時間及穩定次序執行先前已存在的自然安排，再執行原有 NPC 決策 slots。同點的已到期自然變化先於 NPC 活動；新安排至少延遲15分鐘，從當回合實際提交點起算。這保留角色依可知線索選擇續做或中斷、同回合後角色可見先角色成果，以及原本每個 slot 的派送上限。

| t0開始，活動確認15分鐘，完成後15分鐘冷卻；推進15分鐘 | t15提交熱狀態，t30冷卻 |

| 必要條件在一個正式批次被破壞，之後另一批次恢復 | 舊安排永久失效，不隨狀態恢復而復活 |

## 持續條件與保存

安排只綁模型確認的必要狀態鍵，以及必要的目標存在／生命週期條件，不以整世界版本或整份物件 revision 讓無關改變一併失效。每個完整正式批次，以及移動等其他世界變更之後，檢查待執行安排；必要條件不成立即永久失效。單一原子批次內從未提交的中間值不算額外歷史。

已提交的安排不因原活動之後被取消而消失；只有其自身條件失效才停止。未選分支及尚未提交的預測安排不落地。狀態、安排及有界執行／失效紀錄與整回合沿相同 SQLite、版本、租約及操作重送邊界保存，沒有另外的前端計時器或離線運行。

## 替代方案與取捨

將30分鐘拆成兩個15分鐘 tick，即使限制每 NPC 最多一次決策，也會改變到期與關注時機：第一個 tick 免費續做的角色可能錯過原本回合終點應有的新決策；若預先執行階段，又可能違反角色稍後選擇中斷的責任。

先取得所有決策再重排時間，則會改變目前同回合的可知順序；若先做預覽世界讓後角色看到先角色成果，最終重排可能讓角色使用未來才發生的情報。解決這些問題需要另行設計活動／決策引擎，本輪採沿既有實際提交時間的明確表示。

代價是一次推進30分鐘與兩次15分鐘不保證產生相同的角色選擇或完整歷史；既有引擎本來也不提供此保證。此方案保證兩種推進都有可判定的提交順序、無回溯覆寫，以及模型確認時間與真實提交時間可分辨；不宣稱連續物理模擬。舊世界及舊事件不追補自然安排或時間證據。

## #150 有界落實

`schedule-natural@1` 只排受限狀態變更：延遲15–1440分鐘、15分鐘倍數；每安排1–4條件及1–4效果，最多32待執行、64已結算。已結算按結算時間保留，淘汰數另存 `naturalChangesDropped`，不表示完整歷史。不能遞迴安排自然變化或改心理核心。

明示 `changes.from` 亦是持續前提；同一目標可分開不同鍵的曝光效果，但同鍵重複寫入不受支援。條件可只檢查位置／持有guard，缺少guard表示不檢查，而不是要求無持有人。曝光沿物件／環境public或hidden、身體public／subject／hidden，不由排程器補public。

安排者只作來源記錄；到期事件使用world自然來源，離場安排者沒有額外決策、遠端私有線索或主動冷卻行為。舊世界缺少安排不初始化虛構歷史，已保存安排重讀按原時間／狀態續接，不重問模型或重跑已結算後果。
