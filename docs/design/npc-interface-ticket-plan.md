## T2：不同容量模型完成同一決策契約

**Blocked by：** #69。

**交付：** 雲端與模擬本機服務在不同封裝／容量下完成同一世界操作，容量不足有明確失敗，不偷偷刪記憶。

- [ ] 模型容量與輸出預留由轉接設定提供；共用組裝層計入指導、角色與動作資訊，明確區分 bytes 與 tokens。
- [ ] token 精確計算或保守估算的方法與餘裕可檢查，必要內容超限不派送無效請求；不靜默裁剪或另增模型修復。
- [ ] 同一合法候選經不同供應商封裝得到相同驗證與世界結果，不偷偷缺少必填能力。
- [ ] 未選入本次上下文的記憶在重讀時仍存在；已合併記憶契約優先序保持。
- [ ] 模擬本機端點可測，無自動切換付費服務；不實作 Windows 對外橋接、任意網址設定 UI 或部署。
- [ ] 提供適用於後續本機微調的版本化輸入輸出 fixture。

覆蓋 #67 驗收：8、9、10。

## T3：人物四維度與匿名互動目標

**Blocked by：** #69。

**交付：** NPC 可向眼前未知人物說話，也可向已知聯絡人傳訊息，兩條目標路徑互不混淆。

- [ ] 已知人物、可聯絡性、當前感知、身分辨識分開；已有四位角色保持合理初始相容。
- [ ] 當前感知與歷史經歷分區且保留時間，不提供主觀內容的客觀正誤。
- [ ] 當面互動代號不洩漏隱藏身分；模型候選經驗證映射到眼前實際對象。
- [ ] 誤認 Cass 不把當面互動送給真正 Cass；僅認識、僅看到都不自動授予通訊能力。
- [ ] 匿名聲音只提供可知線索／區域，不自動變成可說話人物 target。
- [ ] 跨 NPC 代號拒絕；同一當前感知期間及保存重讀有基本一致性，跨追蹤中斷的完整生命週期由 T4 完成。
- [ ] 不做完整交友或交換聯絡方式系統，不新增人物 UI。

覆蓋 #67 驗收：1、4、5、7，以及 6 的範圍隔離。

## T4：跨回合追蹤與門外腳步完整流程

**Blocked by：** #71。

**交付：** 「聽腳步 → 開門 → 得到實際新觀察 → 下一次決策」可由世界 API 重現，並正確處理目標離開與重新出現。

- [ ] 持續可追蹤時代號保持；失去追蹤且無法確認同一人時不依權威身分自動接回。
- [ ] 歷史代號可作經歷引用，但不能直接作當前互動目標；保存、重讀與失敗回復一致。
- [ ] 開門前無隱藏 Cass 身分；先前「晚點來」訊息只屬歷史經歷。
- [ ] 開門後依當下實際感知產生新觀察；人物已離開／遮擋變體不憑空辨識。
- [ ] 開門、辨識、打招呼不被同一候選偷渡為已完成多步；不重播已停止聲音。
- [ ] 既有開門程式路徑不增加裁定模型呼叫；API 重送不重複效果。

覆蓋 #67 驗收：1、2、3、6、7、14。

## T6：分離世界裁定任務與 NPC 模型路由

**Blocked by：** #69。

**交付：** 從世界 API 執行既有合法行動，裁定輸入與 NPC 上下文各自受限；任務路由可用替身驗證，正式既有行動仍使用程式裁定。

- [ ] NPC 與裁定模型依任務分開設定，任務契約／輸入／請求歷史分離，無自動付費回退。
- [ ] 裁定資料只含行動方法、對象、目的、必要能力／限制／相關物件狀態與規則；不整包帶私人記憶或意圖。
- [ ] 世界 API fixture 可注入受控裁定替身檢查任務隔離與候選驗證，仍走真實執行保存；不建立新公開測試 API。
- [ ] 固定骰值或確定性動作依既有規則驗證後果，模型不得直接寫世界或裁定他人意願。
- [ ] 正式既有動作維持程式路徑與呼叫數；替身案例不是通用自由裁定上線。
- [ ] 自由行動 B 的擴充契約與未決門檻記清楚；不啟用新穎提案的模型呼叫，不實作通用物件效果／未支援提案產品政策。
