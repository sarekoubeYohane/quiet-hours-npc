# 人物能力參與 d100 行動與感知（#277）

依 [已批准 A 方案](character-dice-energy-recommendation-2026-11-09.md)、ADR 0012，承接 [#275人物資料](character-attributes.md)，不另建技能樹、需求懲罰或心理獎勵。只有具有機會及不確定性的嘗試取骰，世界仍先確認有界結果分支與後果合法性。

## 新確認與既有規則

新 wire check 可明示 `{system:'d100-v1',difficulty:8|12|16,ability,attribute:'strength'|'endurance'|'dexterity'|'perception'|null,sense:'sight'|'hearing'|'touch'|null}`。能力關聯由同次世界裁定針對具體方法明示，只選一項；無關四屬性（如社交表達）可為null。`ability` 是領域名稱，與已保存、擁有者確認的專長範圍正規化精確匹配；不是現場新增能力的自由文字授權。

人物已導入時，只有 `resolveRoutineCandidate` 對新模型裁定的候選／program加上 d100版本；未標記的舊 wire check 也可繼續讀取。未導入人物的新裁定保留 D20；讀取、重用舊日常規則及進行中結果不補版本。明示新版仍需人物資料才能使用新能力。舊規則不因後來導入人物而改制，須經真正新確認取得新版。新內建髮飾設計使用靈巧、專長「髮飾設計」；社交表達只用領域「說服」與客觀情境，不把四項身體能力硬套社交。已開始的五分鐘 deferred action 保存 checkSystem，無標記的舊計畫按D20完成。

`Resolution.system='d100-v1'` 保存骰點、成功門檻與五項實際因素；`modifier` 保存因素總和、`dc` 保留三檔客觀難度、`total` 為門檻減骰點，只供觀察者／相容紀錄。舊D20的欄位與總差定義不改寫。人物檔案、行動及感知詳情依保存的版本顯示；NPC的正常輸入仍只有主觀經歷，不取得結果級別、骰點、門檻或診斷。

## 有界計算與不重複因素

`T=clamp(55+(屬性−3)×10+難度+領域專長+感官+關注,10,75)`；難度容易／一般／困難取+20／0／−20，僅取一項已確認領域修正、一項已確認相關感官修正；主動專注+10、普通0、分心−10。沒有確認數字為0，不從角色名／職業／能力文字猜值。屬性或感官的同名中英文範圍不是另一門領域，不能再疊專長。背景本身已壓低屬性的同一弱點也不能由裁定再次列入客觀環境；噪音只歸難度。裁定輸入明示此責任，觀察者可以核對實際因素。

01–05大成功、96–100大失敗；06–T成功、T+1–T+20部分成功、T+21–95失敗（上界75時此段空）。不可能行為、本人意願、他人同意不由極端骰突破。所有受限分支仍先驗證，無效後果／不足投入上限／dry run不取骰，沒有逐顆骰追加模型鏈；成功不自動補精神電量。

同一事件具有多感官不確定線索時，新制按每種感官自身的干擾及已確認修正計算可用T，選最高T路徑、字典序破同分；單骰僅揭露所選路徑的線索，不把容易聽到的機會當作一定看清。排序與來源列舉不決定結果。舊D20保存的群組判定先查回並保留原內容，不藉此工程選擇重新判舊感知。

## 感官硬限制

`characterSetup.blockedSenses` 是擁有者在既有人物／城市設定中明示確認的無感知機會，與1–5能力及±20修正分開。保存至 `Character.attributes.blockedSenses`；缺欄位保留缺值原義，不從「失明」關鍵字或角色名自動生造。正修正與骰01不能解除硬限制。

已形成屬性者從同一人物檔案有限更新硬限制，世界API為 `set-character-sense-limits`、`characterSetup:{blockedSenses}`，帶原版本／context／scope／operation ID。只能更改這份明示列表，不重抽屬性、不改專長數字或精神容量；成功共同寫入後才生效。GET不更新。初始建角與新城市也可直接確認此列表。canSee、canHear、被動線索、直接看見、入場／開門、新不確定判定與主動probe都經同一機會門；明示依賴不可用感官的自由裁定在快取查找前拒絕，不能借舊成功結果繞過。

## 保存、重試與相容

自由結果沿原凍結實質條件與trial key；主動感知沿原probe／resource receipt／機會key。新版本與人物數字不加入key，先承接已保存的D20或d100結果；新operation ID、改DC／能力描述／分組／同義措辭不能洗骰。實際物理條件、有效來源或真正新機會改變時才新取骰。已提交事件、計畫結果、舊project及角色主觀觀察不換算新骰、不重播後果。故障、CAS及提交結果不明仍沿整輪共同保存／操作回放，已知用量保留。
