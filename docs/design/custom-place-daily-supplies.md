# 自訂場所的日常物資

本次需求：自訂場所由天上意志依用途、負責者及權限確認日常材料；食物、水必須能真正取用與攝取，降低飢餓、口渴。補好「霧港鎮・生活測試」，保留原「霧港鎮」，停在第 0 回合。

- 新開局把住戶、工作者、場所主人登記為自訂日常範圍。模型可確認用途相符的普通程序，不強塞咖啡店範本。當前房間仍需通行權與入口通路；背景供應仍遵守有限來源及物件權限。
- 管理存檔提供一次性的第 0 回合「由天上意志準備日常物資」，使用既有付費操作的版本、上下文、租約、收據與用量機制。重送原操作不重複呼叫，另一操作不能再次補貨。失敗不接受部分資源。
- 模型只可提議有限份數、可直接吃喝的供應及既有陳設的日常使用授權。伺服器核對場所身分、房間通路、私人房間、可見性及既有存量。商店通行權不會直接成為商品權；由場所主人明示免費自取才能列入供應。
- 物資形成真正 `SceneSupply`；取用經 `materialize` 形成有身分與數量的物件。身體後果仍由實際行動的 `ingest` 契約確認與執行，備料不改需求數值、不替人物行動。
- 開局認識只提供本人被告知的物資與位置，遠端存量、其他住戶的供應不會洩漏。開局備料不是無限或自動補貨。
- 既有存檔讀取不會補資源或改寫日常資格。只有明示操作的目標世界寫入資源，不改原始開局或其他存檔。

驗證：`tests/opening-resources.test.cjs` 經真實開局、世界 API、保存重讀及實際裁定效果測試；只控制模型傳輸及建角擲骰。實際攝取的測試世界與正式生活測試存檔分開。
