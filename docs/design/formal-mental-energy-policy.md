# 正式精神電量政策核心（#256）

政策依 #271／#256 已確認數字、已批准 A–D 的 D 與 ADR 0012；本核心是 #263 正式啟用的前置，沒有新增 production／UI 啟用入口。

## 形成與版本

`createFormalMentalEnergy(actor, minute, opening)` 是唯一正式狀態工廠，產生 `policy.kind='formal'`、`id='mental-energy-271-v1'`。`opening` 可明示容量、一般容量上下限、目前整數值、階段與工程骰源 seed；不接受額外欄位、矛盾數字或小數。一般容量以兩顆獨立 d6 形成 `(2d6+6)×5`，保存兩顆結果；受背景一般區間限制時在合法骰對中條件抽樣，保留原權重，不反覆重骰。特殊容量須明示正整數，不能以支援集外區間代替。既有精神電量不能由工廠覆寫或將 test 轉正式；#263 對合法既存正式容量／目前值應直接保留。

預設七成、五階中點與半點進位只在開局計算一次；日常感受以共享 BigInt 整數比較實際值／容量分五階，連安全整數上限附近的門檻也不先經浮點取整。容量1預設七成量化為1，實際為充沛，不能強行顯示有餘；調節費仍5、不可負擔。一般初值65×70%=45.5→46。容量較大不放大共用絕對補耗。

沿用舊狀態 writer 所需的共用欄位，正式值由工廠固定形成並完整驗證，不把 test policy 的可調 rates／levels 當正式參數 fallback。`MENTAL_ENERGY_TEST_POLICY` 維持只接受 test；正式狀態只在後續明示啟用流程或本票受控基線形成。

## 世界時間、覆蓋與骰證據

正式狀態只承接已交付的 `five-minute-v1` 時間契約。舊世界中的正式狀態若尚未採用該契約，新十五／三十分鐘 API 操作回400且不前進；明示五分鐘成功寫入可採用。舊受理 ID 仍先精確回放。這避免舊 first-sleep 倒填與正式時間重複預覽混用，沒有新 Issue 依賴。

以絕對世界分鐘 `floor(t/5)` 識別固定格；保存尚未結清的格內覆蓋與0–11實睡單位。同格技術切分累計連續覆蓋，真正格內睡醒／來源起訖／感受版本改變則不構成完整效果。全格清醒才擲自然 d6（1扣1、其他0），全格實睡才累積單位，滿12固定+1；同格持續三級為 d3−1／d3／d3+1。混合格不補自然骰、不累積實睡單位，也不比例計費；半格來源無完整效果。

各骰以已保存 seed、人物、來源及絕對格作 keyed 抽樣，使用拒絕區間映射骰面；同一來源換 transport／陣列次序不換骰。取樣證據隨世界提交，包含面數、骰面、來源、原始補耗及時段；持續效果另保留方向、等級、感受版本與理由。每格先合計自然／持續／恰到期的睡眠+1，再裁切一次；跨格依時序各自裁切，不儲存溢出。

時間讀取已發生的身體／睡眠端點，不預抽需求骰。`activeBodyMinutes` 的 legacy 預估只允許尚未結算的區間；身體已推進後，不能再拿最終睡意反推剛才睡了幾分鐘。v2 自然醒先由真正恢復確立，正式心理格只消費該端點。首個新睡眠的零分鐘 preview 不重做已結清正式時間；`updatedAt` 阻止同段再增減或重增過程投入。

## 經歷、情緒與付款

正式 normal／controlled 模型 schema、prompt 與 parser 一致採0無影響、1輕微、2明顯、3強烈；test 仍保留既有0／1／2契約。一次性各級 d4／d4+2／d4+4，正負共用幅度，無影響不擲骰。取樣以 canonical 來源 ID 固定，不因陣列反序換骰。

已知不同來源時刻依事實先後逐組結算；同刻無先後的合法來源先合計再裁切，組內以穩定來源 ID 保存收據。收據保留每來源 rawDelta／draw；同組共同 before／after 不把裁切損失任意歸給最後一列。晚評價在目前評價點生效，不倒填過去世界。合法時間組完成後，才結算新的一次性組，最後沿既有 `applyEmotionRegulation` 核對固定5點；來源、情緒、付款及 SQLite 仍共同提交。

`assertFormalMentalEnergy(actor)` 是不推進、不抽骰的完整保存狀態驗證入口，供 #263 原樣保留合法既存正式角色；驗證政策、餘額、coverage、來源收據、歷史與過程計數。

`plan.mentalProcess.activeMinutes`／`updatedAt` 是已評估過程的實際投入時間，`draws` 是正式已抽格數；純續做更新，不額外派模型。正式 history 延用32筆有界保留，額外帶每格原始來源與實際餘額；睡眠累積與 pending coverage 獨立於展示歷史，淘汰不影響未來結算。
