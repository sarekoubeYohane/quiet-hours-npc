# 天上意志確認活動規則，活動模組承接生命週期

日常活動若每次重新裁定後果，會增加費用、等待與相似情境下的不一致；全部由程式內建程序決定後果，則限制天上意志承接新方法的能力。決定由天上意志在受限格式內確認條件、耗時、階段、判定需求及有意義的結果分支，日常規則按適用範圍保存重用，自由活動單次裁定不自動升格為日常規則；程式沿既有 D20 取得結果，驗證並執行對應效果，不在每次擲骰後再呼叫模型。

活動模組統一負責開始、推進、到期、取消與清理，透過既有效果驗證器同步更新本回合世界副本與活動進度；NPC 決策、模型派送及整回合保存由外部協調。這讓各入口共用時間與效果語義，並保留 NPC 選擇及既有回合一致性；代價是規則必須有明確邊界、版本及物件重新綁定，不能支援的後果仍須拒絕或走既有例外路徑。

規則核准不是保證成功，保存結果分支也不是把首次骰子結果永久重用。純續做與階段推進不新增模型呼叫或擲骰；同方法同前提保留既有判定。具體介面、儲存結構及相容方案尚待工程落實，不在本 ADR 預先指定。
