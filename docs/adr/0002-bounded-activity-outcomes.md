# 天上意志確認受限結果，活動生命週期負責可靠執行

依 [#125 的自含決策](https://github.com/sarekoubeYohane/quiet-hours-npc/issues/125)，天上意志一次確認活動條件、耗時、階段、必要判定及有意義的結果分支；程式驗證並沿既有 D20、重試與效果契約執行。日常規則可在核准範圍內重新綁定當前合法對象，單次自由裁定不自動變成永久日常規則。五段結果可共用分支，核准不代表開始或完成。

活動生命週期集中開始、推進、到期、取消及清理，透過既有效果驗證器同步修改本回合世界副本與進度。NPC 選擇、模型派送及整回合保存由外部協調，讓活動規則不承擔付費呼叫、角色自主性或資料庫租約；保存失敗仍可沿既有版本、操作日誌與用量邊界回復，而不是分開提交物件與進度。

## 考慮過的替代方案

- **每次結果再裁定**：表達自由度較高，但每次擲骰或階段追加費用、延遲與故障點；後果可能與先前時間、材料或權限衝突。選擇首次受限確認及程式重用，代價是不能任意生成超出既有效果種類的後果。
- **程式內建全部日常效果**：執行可預測、沒有額外推論延遲，但每個方法都需維護程式程序，模型無法確認方法特有的消耗、部分成果或失敗差異。選擇模型確認的有界規則加嚴格驗證，增加契約與重綁維護成本，換取可表達的後果及一致的執行。

## 相容與驗證界線

既有已保存事實與缺少新資料的舊計畫／規則須保持可讀，不補造「模型已確認」的失敗後果。具體介面與資料表示由工程實作決定；本 ADR 不接受未選定的遷移政策。#122／#123 是獨立契約及工具／容器修正，本輪沿用其成果並回歸，不以本決策取代其驗收。實作及 fixture／真實模型的驗證狀態以本輪驗證紀錄為準，決策本身不代表正式站通過。
