# 身體時間、實際後果與主觀生活證據共同提交

[#172](https://github.com/sarekoubeYohane/quiet-hours-npc/issues/172) 已確認：身體提供需求，角色自主取捨；實際可知經驗可以形成喜好，真正開始的自主選擇可以累積習慣。沿用既有整輪候選、世界效果、記憶可見性與操作恢復，不另建逐 tick 生理／喜好／習慣模型。

四項需求是有界世界狀態，時間更新由程式負責，活動後果由既有天上意志裁定確認並按實際分鐘或消耗提交。角色只收到本人可感文字；原身體狀態字串不能旁路改寫權威需求。需求升級提供一次正常重新評估機會，不指定意圖、強制中止或增加能力懲罰。喜好與成敗／需求滿足分開保存；習慣與完成／喜歡分開保存。這需要明確來源、版本、容量與缺口，不能由舊敘述補造生活歷史。

共同活動擴為有限的數小時世界時間，修訂原 #115 的90分鐘界線；每次 HTTP 仍只處理既有世界推進量。可恢復活動由世界明示確認，暫停保存進度但不凍結環境；復工由角色選擇且重驗當前條件，不重播消耗、階段或骰子。實際睡眠與清醒休息分開，技術區段結束不能代替醒來原因。伺服器期限、固定租約、預算與模型派送政策維持既有契約。

代價是世界 JSON 與主觀證據增加有界資料，新欄位寫入後舊 binary 不能保證理解完整時間、進度與資訊語義。選擇保留舊資料、不回填、不自動重置，並在首個適用可寫操作明示啟用；舊規則缺新後果仍維持原義。回退須保留新版資料與可理解的執行器，不以丟棄欄位恢復。

工程參數、版本與理由見 [自主生活工程契約](../design/autonomous-life.md) 及各切片基線；具體數字不是使用者已確認的產品平衡值。accepted 表示上述產品方向已確認，不表示正式站或真實模型行為已驗收。本地可控 transport 的一致性與真實 NPC 自主生活分開報告。
