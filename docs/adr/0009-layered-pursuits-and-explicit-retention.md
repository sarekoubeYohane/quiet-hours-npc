# 追求以唯一分層狀態明示變更，舊世界由明示重置導入

#220 已確認平面完整陣列的省略退出無法分辨漏寫與放下。以同一 `Character.intents` 擴充分層身份、版本、範圍與主觀標準，正常決策只提交明示增量；設定提供方向起點，後續可自主修訂。活動保留一份真實進度，追求只作關聯，世界與意願沿原整輪 CAS／journal 提交。這修訂原 #1 的表示及省略規則，不增加獨立模型或固定職業任務。

選擇明示重置測試世界取代完整舊意圖遷移，避免用工程猜測補造舊範圍、滿足標準與關係。代價是舊世界可讀但在不相容推進前停止，不能自動重置或清除用量；新版資料回退須保留新語義執行能力。私人痕跡不進 NPC，來源遺忘沿既有可知投影。

工程值與切片限制見[工程契約](../design/layered-pursuits.md)。accepted 表示沿用已確認產品設計，不表示 #220 全部實作或真實 NPC 行為已通過。

#222 補充：候選、收斂與正式增量在原同一次最終決策中明示，候選不自動取得承諾或外在可行性。未承接內容只進既有有界私有實錄，避免形成第二套永久待辦或記憶旁路；代價是候選只在有限追溯窗口可核對，不能從缺失資料重建心理因果。程式驗證身份、版本、可見來源和結構映射，不增加模型評分或付費語義裁判。容量及實作證據見[同次發散收斂](../design/pursuit-selection.md)。

#223 將支援關係擴充為有界 DAG。共享工作仍在同一節點與活動中，局部順序只保存各支援邊的位置，根順序沿唯一節點集合中的位置；不以重要性相乘、職業規則或拓撲順序替角色選行動。這比複製各上層任務或自動執行工作流多了關係／版本檢查成本，換取共享進度和跨分支自主選擇。明示局部重排保留未列項目，世界必要前提仍由原效果／活動流程驗證。

#224 把主觀滿足與外在活動完成分開：正常決策可以明示滿足、仍追求但等待／延期／受阻，或持續方向目前足夠。採同一節點的短評與有效來源身份，不由活動完成、成果產生或需求變化自動推定滿足；代價是需要讀者同時核對模型短評與世界結果。本人誤解與感受仍可影響評估，不增加真相校正／語義裁判模型。已滿足身份保留，不由提醒或既有方向復活；純活動推進維持零新增決策與唯一物理進度。

#225 以同批明示的下層增量處理上層改寫與退出，不採全面級聯刪除或自動剝除關係；共享工作的其他動機繼續成立。範圍變更和主觀評估可在同次使用相同原版本，分兩段保存前後差異，避免縮小後滿足冒充原大成果。活動沿原生命週期，另保留開始時的追求身份／版本；轉接只改目前支援關聯，不回寫歷史或複製進度。代價是大範圍退出可能需先分批明示轉接／獨立再退出上層，及來源歷史仍受有界痕跡限制；不增加回合額度或模型呼叫。
