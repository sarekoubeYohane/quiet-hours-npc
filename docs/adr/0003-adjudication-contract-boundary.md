# 裁定契約集中維護，與世界執行分離

裁定提示、回覆格式及解析若分別維護，同一條限制容易出現互相矛盾的要求；先前日常完成時間衝突已由 #122／PR #124 修正，本決策處理後續維護責任。決定將天上意志裁定的共同限制集中定義，提示與回覆格式盡量由此產生，不能自動產生的語意及跨欄位規則由明確驗證與一致性測試保護；不要求生成整段自然語言提示，也不建全專案通用契約框架。

契約模組只產生、解析及驗證裁定候選，不綁定物件、保存規則或修改世界；活動流程再依當前權威世界綁定對象，透過既有效果驗證器執行並更新進度，外部協調既有派送與保存。這延續 #125 的責任邊界，讓解析可獨立驗證且不產生世界副作用；代價是候選符合契約仍不能保證當前可執行，執行前及各階段仍需驗證前提，不能把兩層檢查混為同一項成功判斷。

本輪限天上意志的世界裁定，包括日常核准、一般自由活動與 #125 的結果分支；NPC 決策／回想契約另行整理，保留不同角色目的與資訊邊界。未選擇將規則綁定併入契約模組、各處手寫同一限制僅靠測試對齊，或一併重構所有模型契約；這些方案分別增加副作用耦合、維護漂移或變更範圍。既有 D20、錯誤處理、預算／派送上限及保存／回復規則維持原契約。
