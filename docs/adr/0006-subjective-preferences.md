# 喜好由本人經驗評價，與認知和世界後果分開保存

#172／#178 已確認喜好不能由成功、需求滿足、重複次數或裁定級別直接推得。沿正常 NPC 決策加入明示喜好更新，僅允許當次實際可見的本人經驗版本；程式負責來源、身份、容量與原子性驗證，不替角色選擇喜惡或覆寫意圖。

使用獨立角色資料，避免把信念確信度重新命名成喜歡程度。現行喜好及觀察者短痕跡分開投影；保留上界、釋放計數與來源缺口，避免舊看法變成角色仍相信／喜歡的事物。所有變更與活動、記憶同輪提交，不增加獨立模型呼叫。

工程值與相容政策見 [基線](../design/life-preferences-baseline.md)。accepted 表示沿用已確認產品方向，並非這些參數是使用者已確認，也不表示真實模型或正式站完成行為驗收。
