# 世界裁定可確認有界的新物件狀態

逐項預列所有物件狀態，會讓合理活動因未寫入某個狀態而無法承接，也使 #125 所選的後果決定權退回固定活動劇本。決定允許天上意志在受約束的狀態描述內確認並保存新物件狀態，仍保留身份、權限、既有事實及資料大小等檢查；不因此允許任意世界 patch、模型產生程式或新增效果種類。

相較於每遇到「有茶漬」「濕潤」等狀態便修改程式，此方向容許方法與後果有更多變化，代價是必須明確處理狀態語意、矛盾、規則適用及可追蹤性。這些細節仍在訪談中，本 ADR 只記錄已確認的能力邊界，不預先決定資料結構、相容或遷移方案，也不放寬現行全域驗證器。
