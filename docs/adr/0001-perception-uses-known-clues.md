# 關注條件以角色已察覺線索比對

世界可能知道事件的完整來源與原因，但 NPC 只能接觸部分線索。直接以完整事件比對較容易，卻會讓角色因系統掌握的真相而提前察覺尚未辨識的身分。

決定僅以該 NPC 已察覺的線索比對關注條件；未知來源保持未知，期待與猜測不替代辨識。此邊界影響提前決策及後續資訊的保存，避免未經察覺的真相滲入角色所知內容。

例：等 Vera 的角色隔著門聽見腳步時，可以關注「有人靠近」，但辨識前不能直接匹配「Vera 到了」。設計已於 2026-10-10 的感知 Grill 7 確認，尚不代表功能已實作。

後續補充（Grill 22–25）：感知大失敗可產生錯誤的主觀感官內容，包含誤認熟人或沒有對應外在刺激的感受。關注條件同樣比對角色實際取得的主觀內容；若主觀誤認 Vera，可因該誤認觸發關注，不能因世界知道其錯誤而抑制。候選來源限角色既知／期待資訊，不直接讀取事件的隱藏真實身分。世界真相與診斷標記仍不進入角色上下文。此補充維持本 ADR 的核心資訊邊界，同時明確區分真實辨識與錯誤感知。
