# 關注條件以角色已察覺線索比對

世界可能知道事件的完整來源與原因，但 NPC 只能接觸部分線索。直接以完整事件比對較容易，卻會讓角色因系統掌握的真相而提前察覺尚未辨識的身分。

決定僅以該 NPC 已察覺的線索比對關注條件；未知來源保持未知，期待與猜測不替代辨識。此邊界影響提前決策及後續資訊的保存，避免未經察覺的真相滲入角色所知內容。

例：等 Vera 的角色隔著門聽見腳步時，可以關注「有人靠近」，但辨識前不能直接匹配「Vera 到了」。設計已於 2026-10-10 的感知 Grill 7 確認，尚不代表功能已實作。

後續補充（Grill 22–25）：感知大失敗可產生錯誤的主觀感官內容，包含誤認熟人或沒有對應外在刺激的感受。關注條件同樣比對角色實際取得的主觀內容；若主觀誤認 Vera，可因該誤認觸發關注，不能因世界知道其錯誤而抑制。候選來源限角色既知／期待資訊，不直接讀取事件的隱藏真實身分。世界真相與診斷標記仍不進入角色上下文。此補充維持本 ADR 的核心資訊邊界，同時明確區分真實辨識與錯誤感知。

## #157 實作補充：可知行動回饋

一般裁定、日常執行及活動階段沿既有 `record → 短期經歷 → 下一次模型輸入` 保存原提案／對象及時點，續做仍不新增決策。採既有 NPC 物件投影重述持有或指定物件的已知公開狀態，並明示它是既有狀態，不能把它當成本次新成果或受阻原因。已知物件身份不表示角色知道供應餘量或私有使用許可；即使日常程式已生成原因，也不能直接灌入角色經歷。

角色自己設定的投入上限與已確認耗時可直接說明；其他程式或模型理由留作觀察者診斷。已提交階段僅描述其步驟與可知成果，不暴露內部五段級別，隱藏狀態值不從效果摘要旁路送入。既有觀察／聽聞及錯誤主觀感知維持原來源，回饋不以隱藏真相校正；餐點已消耗等知識須來自原有角色經歷，而非裁定自述。完整原提案與本人已知語境透過 `actorExperience` 保存，旁人仍由原本公開事件及感知機制取得線索。

沒有新增持久化知識儲存、回饋生成模型呼叫或保存 migration；短期經歷沿原 80 筆、64 KiB 及總記憶容量淘汰，舊世界讀取不補造回饋。限制與本地替身驗證見 [#157 驗證紀錄](../verification/action-feedback-157-2026-10-22.md)，不代表真實模型已停止重複或正式站已通過。

## #344 補充：回饋開頭只引用原提案

本人行動回饋的開頭原本不論成功或受阻都寫「原提案，非已發生成果」。真實模型把成功的回饋讀成沒有發生並重提同一提案（[#344](https://github.com/sarekoubeYohane/quiet-hours-npc/issues/344) 的重放：同一份請求只拿掉這幾個字，重提由 10/10 降到 2/10）。開頭改為只引用原提案（「原提案：…」），有沒有發生一律由結果句說明：

- 結果句列出已提交的成果時，本人經歷以「已發生：」起頭；不經階段、當下提交完畢的行動另加「這次行動已完成。」
- 受阻、不支援與尚在進行的結果句不變，仍自行說明尚未執行或尚未完成。
- 「已發生：」只進本人經歷。旁人感知用的事件文字與觀察頁的活動文字維持原樣，知情邊界不變。

沒有新增知識來源、模型呼叫或保存 migration；既有世界中已保存的舊開頭經歷不改寫，依原容量自然淘汰。

### 否決時接回本人吃過的事

本人的行動實際吃掉物件時，該次事件記下吃掉的是什麼（`WorldEvent.actorConsumed`：物件、來源與當時的名稱）。之後同一人對同一物件或同一來源的提案不成立、且沒有本人已知的受阻原因時，回饋在原句之後加上「依自己記得的經歷：世界時間 N 自己已食用…」。

- 來源只有本人仍保有的短期經歷：那筆經歷已淘汰或被移除時不加，回到「未確認本次受阻的原因」。不讀供應餘量、使用許可或裁定自述。
- 這句話只重述本人已知的事，不宣稱它就是受阻原因，原本的「未確認本次受阻的原因」保留。
- 別人吃掉而本人沒有經歷時不加。本人只看見或聽說別人吃掉、經歷已選留到長期記憶但短期已淘汰，這兩種情況目前都不接回。
- 只涵蓋食用。毀壞、轉交等其他讓物件離開本人視野的行動不在此列。
- 既有存檔的舊事件沒有這個標記，不回補。沒有新增模型呼叫或保存 migration。

## #207 物品觀察補充

主動查看沿同一主觀感知／短期經歷加入既有未知物品，清晰察覺才承接既有 knownTo；移動、模糊線索、漏看不授予身份。optional objectId／來源 object 與人物來源分開，發現不取得持有或許可。沒有新增模型或 SQL migration；容量與舊世界／回退見[工程契約](../design/object-observation.md)，本機 API／SQLite／真正下一請求與既有畫面證據見[#207 驗證](../verification/object-observation-207-2026-10-28.md)，不代表真實 NPC 自主行為已改善。

## #208 自由查找補充

`world-effects.v5` 的受限 discover v1 將本次世界確認與角色實際感知分開。權威當地候選可含未知物品／供應，角色輸入仍只用本人可知投影。clone、分支、日常編譯及完成上限預檢不感知；真正活動提交後沿既有觀察／經歷承接。供應新增 optional supplyId／來源 supply，不直接曝光庫存或授予持有／許可。容量、同條件去重、相容及回退見[工程契約](../design/world-discovery.md)；本票程式與既有畫面證據見[#208 驗證](../verification/world-discovery-208-2026-10-28.md)。
